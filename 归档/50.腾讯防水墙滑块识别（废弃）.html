腾讯防水墙滑块识别 ​

演示如何用 OpencvOps 基础接口实现腾讯防水墙「拼图滑块验证码」的目标缺口定位。

这类图片横向排列 3 个拼图：

  • 最左：浅色描边的源滑块
  • 中间、最右：两个深色拼图，其中一个是真实目标，一个是干扰项
  • 3 个拼图的 Y 接近，真实目标与源滑块的外接框宽高、中心 Y 最接近

极简思路 ​

核心分成两件事：

  1. 找出 3 个拼图外接框：源框在左侧，两个候选框在右侧
  2. 在两个候选框里，选与源框 width / height / centerY 最接近的那个

本地样本验证：

  • 目录：Captcha/slider_capture/samples_puzzle
  • 使用已打标的 57 张图片做粗框输入验证
  • 命中：53 / 57
  • 准确率：92.98%

纯阈值轮廓在复杂背景上容易把建筑、树影、文字一起识别进来；生产环境建议用 YOLO 只做三框粗定位，再用下面的 OpenCV 几何规则区分真实目标和干扰项。这样 Lua 代码最短，框大小也最统一。

Lua 示例 ​

lua
-- 腾讯防水墙拼图：三框定位后，用宽高/Y一致性区分目标和干扰项
local UtilsMain = loader.loadClass('com.xfx.plugin.UtilsMain')
UtilsMain.init(LuaEngine.getContext())

local opcvOps = UtilsMain.opencvOps()

local function toBox(r, score)
    local w, h = r.right - r.left, r.bottom - r.top
    return {
        score = score or 0.98,
        left = r.left, top = r.top, right = r.right, bottom = r.bottom,
        width = w, height = h,
        centerX = math.floor((r.left + r.right) / 2),
        centerY = math.floor((r.top + r.bottom) / 2)
    }
end

local function boxJson(r)
    return string.format(
        '{"score":%.2f,"left":%d,"top":%d,"right":%d,"bottom":%d,"width":%d,"height":%d,"centerX":%d,"centerY":%d}',
        r.score, r.left, r.top, r.right, r.bottom, r.width, r.height, r.centerX, r.centerY
    )
end

local function sameShapeScore(src, r)
    return math.abs(r.width - src.width)
        + 2 * math.abs(r.height - src.height)
        + 2 * math.abs(r.centerY - src.centerY)
end

local function chooseTarget(sourceRect, candA, candB)
    local src = toBox(sourceRect, 0.98)
    local a = toBox(candA, 0.96)
    local b = toBox(candB, 0.96)
    local target = a
    if sameShapeScore(src, b) < sameShapeScore(src, a) then
        target = b
    end
    return src, target
end

-- 1. 读取图片（或 LuaEngine.snapShot 后 bitmapToMat）
local img = opcvOps.readResMat("/sdcard/Download/slider.png")
if img == "" then print("读取图片失败"); return end

-- 2. V 通道二值化，取轮廓框作为粗定位候选
local V = opcvOps.getHSV(img, 2)
local light = opcvOps.threshold(V, 150, 255, 0)       -- 浅色源滑块
local dark = opcvOps.threshold(V, 110, 255, 1)        -- 深色目标/干扰

local W, H = opcvOps.getWidth(img), opcvOps.getHeight(img)
local lightRects = jsonLib.decode(opcvOps.getContoursRect(light, 1, 2, ""))
local darkRects = jsonLib.decode(opcvOps.getContoursRect(dark, 1, 2, ""))

local function pickSource(rects)
    local best = nil
    for i = 1, #rects do
        local r = rects[i]
        local rw, rh = r.right - r.left, r.bottom - r.top
        if r.left < W * 0.35 and rw >= 30 and rw <= 70 and rh >= 30 and rh <= 70 then
            if best == nil or rw * rh > (best.right - best.left) * (best.bottom - best.top) then
                best = r
            end
        end
    end
    return best
end

local function pickCandidates(rects)
    local arr = {}
    for i = 1, #rects do
        local r = rects[i]
        local rw, rh = r.right - r.left, r.bottom - r.top
        if r.left > W * 0.30 and rw >= 30 and rw <= 75 and rh >= 28 and rh <= 75 then
            arr[#arr + 1] = r
        end
    end
    table.sort(arr, function(a, b) return a.left < b.left end)
    return arr[1], arr[2]
end

local sourceRect = pickSource(lightRects)
local candA, candB = pickCandidates(darkRects)

if sourceRect and candA and candB then
    local source, target = chooseTarget(sourceRect, candA, candB)
    print("源滑块: " .. boxJson(source))
    print("目标缺口: " .. boxJson(target))

    local boxed = opcvOps.drawRect(img, source.left, source.top, source.right, source.bottom, "#4F8CFF", 2, false, true)
    boxed = opcvOps.drawRect(boxed, target.left, target.top, target.right, target.bottom, "#28C9A1", 2, false, true)
    opcvOps.save(boxed, "/sdcard/Download/slider_result.png")
else
    print("纯 OpenCV 粗定位失败，建议改用 YOLO 输出三框后调用 chooseTarget")
end

opcvOps.clear()

YOLO 粗框结合方式 ​

如果已经用 xfxYolo 打出了 3 个框，推荐只让 YOLO 做粗定位：

  • 源滑块：传给 sourceRect
  • 真实匹配缺口 / 干扰假缺口：不直接相信类别，统一作为两个候选传给 candA / candB
  • 仍然用 chooseTarget(sourceRect, candA, candB) 做最终判别

这样能避免背景干扰，同时保留 OpenCV 的简洁几何规则。

说明 ​

  • 返回结构统一为：
json
{"score":0.98,"left":100,"top":50,"right":160,"bottom":80,"width":60,"height":30,"centerX":130,"centerY":65}
1
  • 如果目标和干扰的尺寸非常接近，可再加一项侧边形状投影差作为平局裁决；但当前样本中，宽高和中心 Y 已经是最高性价比规则。
  • 不建议新增“腾讯滑块专用接口”。如需增强，优先增加基础能力，例如通用 matchShapes 或更完整的 Hu 矩输出。
