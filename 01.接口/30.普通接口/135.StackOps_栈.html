模块简介 ​

StackOps 提供线程安全的栈管理，支持按 ID 持有多个栈，覆盖创建、入栈/出栈、查看栈顶、状态查询、清空/删除以及导出 JSON。

功能概览 ​

  • 栈管理：创建/删除栈实例
  • 入栈出栈：入栈、出栈、查看栈顶
  • 状态查询：获取大小、判断是否为空
  • 清理与导出：清空栈、转为 JSON 数组字符串

API 接口列表 ​

1. 栈管理 ​

create() ​

创建或获取栈实例（若已存在则直接返回 true）。

参数名类型必填说明
idString是栈唯一标识
返回值类型说明
Boolean创建/获取成功返回 true

示例：

lua
local stackOps = UtilsMain.stackOps()
print(stackOps.create("s1"))

delete() ​

删除栈实例。

参数名类型必填说明
idString是栈唯一标识
返回值类型说明
Boolean删除成功返回 true

示例：

lua
local stackOps = UtilsMain.stackOps()
print(stackOps.delete("s1"))

2. 入栈出栈 ​

push() ​

将元素压入栈顶。

参数名类型必填说明
idString是栈唯一标识
elementString否元素内容，空则存入空串
返回值类型说明
Boolean入栈成功返回 true

示例：

lua
local stackOps = UtilsMain.stackOps()
stackOps.create("s1")
print(stackOps.push("s1", "item1"))

pop() ​

从栈顶移除并返回元素。

参数名类型必填说明
idString是栈唯一标识
返回值类型说明
String?栈顶元素，栈空或失败返回 null

示例：

lua
local stackOps = UtilsMain.stackOps()
stackOps.create("s1")
stackOps.push("s1", "item1")
print(stackOps.pop("s1"))

3. 查看元素 ​

peek() ​

查看栈顶元素但不移除。

参数名类型必填说明
idString是栈唯一标识
返回值类型说明
String?栈顶元素，栈空或失败返回 null

示例：

lua
local stackOps = UtilsMain.stackOps()
stackOps.create("s1")
stackOps.push("s1", "item1")
print(stackOps.peek("s1"))

4. 状态查询 ​

size() ​

获取栈大小。

参数名类型必填说明
idString是栈唯一标识
返回值类型说明
Int大小，栈不存在返回 -1

示例：

lua
local stackOps = UtilsMain.stackOps()
stackOps.create("s1")
stackOps.push("s1", "item1")
print(stackOps.size("s1"))

isEmpty() ​

判断栈是否为空。

参数名类型必填说明
idString是栈唯一标识
返回值类型说明
Boolean为空返回 true

示例：

lua
local stackOps = UtilsMain.stackOps()
stackOps.create("s1")
print(stackOps.isEmpty("s1"))

5. 清理与导出 ​

clear() ​

清空栈中的所有元素。

参数名类型必填说明
idString是栈唯一标识
返回值类型说明
Boolean清空成功返回 true

示例：

lua
local stackOps = UtilsMain.stackOps()
stackOps.create("s1")
stackOps.push("s1", "item1")
print(stackOps.clear("s1"))

toJsonArray() ​

将栈元素转为 JSON 数组字符串（顺序为栈底到栈顶）。

参数名类型必填说明
idString是栈唯一标识
返回值类型说明
StringJSON 数组字符串，失败或不存在返回 "[]"

示例：

lua
local stackOps = UtilsMain.stackOps()
stackOps.create("s1")
stackOps.push("s1", "item1")
stackOps.push("s1", "item2")
print(stackOps.toJsonArray("s1"))

完整示例 ​

lua
import('com.nx.assist.lua.LuaEngine')
local loader = LuaEngine.loadApk('xfxPlugin-release.apk'); assert(loader)
local context = LuaEngine.getContext()
local UtilsMain = loader.loadClass('com.xfx.plugin.UtilsMain'); assert(UtilsMain)
UtilsMain.init(context)

local stackOps = UtilsMain.stackOps()

-- 创建
print("create:", stackOps.create("s1"))

-- 入栈
print("push1:", stackOps.push("s1", "item1"))
print("push2:", stackOps.push("s1", "item2"))

-- 查看
print("peek:", stackOps.peek("s1"))

-- 状态
print("size:", stackOps.size("s1"))
print("isEmpty:", stackOps.isEmpty("s1"))

-- 出栈
print("pop:", stackOps.pop("s1"))
print("peek after pop:", stackOps.peek("s1"))

-- 导出 JSON（栈底到栈顶）
print("json:", stackOps.toJsonArray("s1"))

-- 清空
print("clear:", stackOps.clear("s1"))
print("size after clear:", stackOps.size("s1"))

-- 删除
print("delete:", stackOps.delete("s1"))

注意事项 ​

  • ID 一致性：所有操作需使用同一栈 ID；未创建的 ID 将导致操作失败。
  • 并发安全：内部使用 ConcurrentHashMap 与 Stack，适用于多线程场景，但调用方仍需按需同步业务逻辑。

栈和队列区别 ​

对比维度栈（Stack）队列（Queue）
存取规则后进先出（LIFO），最后存入的最先取出先进先出（FIFO），最先存入的最先取出
操作端仅在同一端（栈顶）进行入栈、出栈两端分离：队尾入队，队头出队
核心操作入栈(push)、出栈(pop)、取栈顶(peek)入队(enqueue)、出队(dequeue)、取队首(peek)、取队尾(peekLast)
形象比喻手枪弹夹、叠放的盘子排队购票、水管流水
典型应用函数调用栈、表达式求值、括号匹配、回溯消息队列、任务排队、广度优先搜索(BFS)
遍历顺序逆序访问存入元素顺序访问存入元素
