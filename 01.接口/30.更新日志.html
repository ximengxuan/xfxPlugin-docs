更新日志 ​

2026-08-31 1.0.19 ​

  • 新增：OpencvOps 屏幕绘制异步接口。
  • 变更：YoloOps.init() 支持自动根据 NCNN param 推断模型输入尺寸。
  • 修复：YOLO检测结果中 score 输出被四舍五入成 0 的问题。
  • 优化：YoloOps.status() 返回的模型路径不再显示 JSON 转义斜杠。
  • 优化：OpencvOps.findPolygonsEx多边形检测接口。高阈值网格检测时，不再向网格左右两侧凭空外推补格。

2026-08-29 1.0.18 ​

  • 优化：OpencvOps.matchGradientShape() 支持读取多角度梯度 YAML，并在匹配 JSON 中返回可选 angle / directionAngle / directionAngleClock 字段。
  • 新增：OpencvOps.maskRects() / maskExcludeRects() 支持给指定区域或排除区域外叠加可调透明度遮罩。
  • 新增：OpencvOps.blurExcludeRects() / mosaicExcludeRects() 支持保留指定区域，其他区域全部模糊或马赛克。
  • 优化：ScreenOps.snapShot() / snapShotByShell() / snapShotByScrcpy() 复用内部 su 会话，减少每次截图重复弹出 root 授权 toast 并被截入图片的问题。
  • 变更：ScreenOps.snapShotByShell() 移除 isRoot 参数。

2026-08-28 1.0.18 ​

NOTE

本次为OpencvOps和ImageOps重要更新，涉及多项变更。

  • 新增：OpencvOps.clip() 按左上角和宽高裁剪 Mat 区域。
  • 新增：OpencvOps.addTextWatermark() / addImageWatermark() Mat 链路水印接口。
  • 新增：OpencvOps.round() 支持 Mat 圆形与圆角处理。
  • 新增：OpencvOps.save() 指定格式和质量保存图片。
  • 新增：OpencvOps.saveToAlbum() 保存 Mat 图片到系统相册。
  • 新增：OpencvOps.compress() 通用压缩接口。
  • 新增：OpencvOps.getInfo(matId) Mat 信息查询接口。
  • 变更：明确 OpencvOps 为连续图像处理主链路，ImageOps 保留为 Bitmap 工具箱；重复接口采用兼容保留、文档迁移推荐策略。
  • 新增：OpencvOps.clone(matId) Mat 深拷贝接口。
  • 变更：新增 OpencvOps.scale(matId, scaleW, scaleH) 自动缩放入口，与 ImageOps.scale() 统一命名和参数规则。
  • 变更：OpencvOps.getMatInfo()改名为OpencvOps.getInfo()，增加返回字段。
  • 变更：OpencvOps.clearMats()改名为OpencvOps.clear()。
  • 变更：OpencvOps.saveMat()改名为OpencvOps.save()。
  • 变更：OpencvOps.matThreshold()改名为OpencvOps.threshold()。
  • 变更：OpencvOps.matDoubleThreshold()改名为OpencvOps.doubleThreshold()。
  • 变更：OpencvOps.matAdaptiveThreshold()改名为OpencvOps.adaptiveThreshold()。
  • 变更：OpencvOps.resizeMat()改名为OpencvOps.scale()。
  • 变更：OpencvOps.matToGray()改名为OpencvOps.gray()。
  • 新增：OpencvOps.compare(matId1, matId2, method) Mat 相似度比较接口。
  • 新增：OpencvOps.blurRects() / mosaicRects() 支持对单个或多个矩形区域做模糊处理。
  • 变更：ImageOps.toGray()改名为OpencvOps.gray()。
  • 变更：ImageOps.toRound()改名为OpencvOps.round()。
  • 新增：联想单缺口滑块识别案例，使用 OpencvOps 基础接口返回右侧白色拼图区块 left/top/right/bottom。
  • 新增：OpenCV 图片区域模糊打码案例。
