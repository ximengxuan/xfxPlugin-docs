# OpencvOps\_图像处理

## 模块简介

`OpencvOps` 提供常用图像预处理能力。

* **系统要求**：Android 7.0+（minSdk 24）

## 功能概览

* **统一转换**：`bitmapToMat(bitmap)` —— Bitmap 转 Mat 句柄（入口）
* **读取文件**：`readResMat(path)` —— 从图片文件读取为 Mat
* **尺寸查询**：`getWidth(matId)` / `getHeight(matId)` —— 获取 Mat 宽高
* **灰度处理**：`matToGray(matId)` —— 彩色图转单通道灰度图
* **二值化处理**：`matThreshold(matId, thresh, maxval, type)` —— 固定阈值二值化
* **双阈值二值化**：`matDoubleThreshold(matId, lowThresh, highThresh, maxval)` —— 区间保留二值化
* **自适应二值化**：`matAdaptiveThreshold(matId, maxValue, adaptiveMethod, thresholdType, blockSize, c)` —— 局部自适应二值化
* **颜色空间转换**：`getHSV(matId, type)` / `getHLS(matId, type)` / `getBGR(matId, type)` —— 全图或单通道
* **边缘检测**：`findCannys(matId, threshold1, threshold2, apertureSize, L2gradient)` —— Canny 边缘检测
* **形状检测**：`findLines` / `findCircles` / `findPolygons` —— 直线 / 圆 / 凸包形状检测
* **凸包**：`getConvexHull` / `isContourConvex`
* **轮廓处理**：`getContours` / `getContoursRect` / `getContoursCircles` / `getContoursLength` / `getContoursArea` / `getContoursHierarchy` / `getContoursMoments`
* **形态学操作**：`dilate` / `erode` / `open` / `close` / `topHat` / `blackHat` / `gradient` / `skeleton`
* **滤波**：`absDiff` / `medianBlur` / `gaussianBlur` / `blur` / `bilateral` / `filter2D`
* **颜色范围 / 掩膜**：`inRange` / `copyTo`
* **区域操作**：`cropMat`（裁剪） / `drawRect`（画框） / `findImg`（模板匹配找图）
* **几何变换**：`warpPerspective`（透视变换）
* **投影**：`projection` / `projectionValue`（行 / 列投影）
* **保存**：`saveMat(matId, path)` —— Mat 句柄保存为图片文件（自动创建父目录）
* **回收**：`recycle(matId)` / `clearMats()` —— 释放 Mat 池内存
* **回收校验**：`isRecycled(matId)` —— 判断 Mat 句柄是否已回收

## API 接口列表

### 统一转换

#### bitmapToMat(bitmap)

将 Bitmap 存入 Mat 池，返回 Mat 句柄。这是 Bitmap 进入处理链路的统一入口。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| bitmap | Bitmap | 是 | 输入 Bitmap（如懒人精灵截图） |

| 返回值类型 | 说明 |
|-----------|------|
| String | Mat 句柄（如 `mat_1`），失败返回 `""` |

#### matToBitmap(matId)

将 Mat 句柄转回 Bitmap。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | Mat 句柄 |

| 返回值类型 | 说明 |
|-----------|------|
| Bitmap | Bitmap 对象，失败返回 null |

#### readResMat(path)

从图片文件读取为 Mat 句柄，存入 Mat 池。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| path | String | 是 | 图片文件绝对路径，如 /storage/emulated/0/Pictures/img.png |

| 返回值类型 | 说明 |
|-----------|------|
| String | Mat 句柄，路径不存在或解码失败返回 `""` |

**示例：**

```lua
local img = opcvOps.readResMat("/sdcard/Download/K歌滑块实例_img_1.png")
if img ~= "" then
    -- 处理 img
end
```

#### getWidth(matId)

获取 Mat 的宽度（像素）。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | Mat 句柄 |

| 返回值类型 | 说明 |
|-----------|------|
| Int | 宽度像素数，句柄不存在返回 -1 |

#### getHeight(matId)

获取 Mat 的高度（像素）。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | Mat 句柄 |

| 返回值类型 | 说明 |
|-----------|------|
| Int | 高度像素数，句柄不存在返回 -1 |

**示例：**

```lua
local W = opcvOps.getWidth(img)
local H = opcvOps.getHeight(img)
```

### 灰度处理

#### matToGray(matId)

将彩色图转换为单通道灰度图（BGR -> GRAY），是二值化、边缘检测等预处理的第一步。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄 |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄（单通道灰度图），失败返回 `""` |

### 二值化处理

#### matThreshold(matId, thresh, maxval, type)

将灰度图按固定阈值分成黑白两值（0 或 maxval）。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄 |
| thresh | Double | 是 | 阈值（0~255） |
| maxval | Double | 是 | 最大值（一般为 255） |
| type | Int | 是 | 二值化类型，见下表 |

**type 取值：**

| type | 名称 | 说明 |
|------|------|------|
| 0 | 二值化 BINARY | src > thresh 取 maxval，否则取 0 |
| 1 | 反向二值化 BINARY\_INV | src > thresh 取 0，否则取 maxval |
| 2 | 截断 TRUNC | src > thresh 取 thresh，否则取原值 |
| 3 | 取零 TOZERO | src > thresh 取原值，否则取 0 |
| 4 | 反取零 TOZERO\_INV | src > thresh 取 0，否则取原值 |
| 8 | OTSU | 大津法自动计算阈值（thresh 作为初始值） |
| 16 | TRIANGLE | 三角法自动计算阈值 |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄，失败返回 `""` |

### 双阈值二值化

#### matDoubleThreshold(matId, lowThresh, highThresh, maxval)

通过两次阈值实现 **区间保留**：低于 `lowThresh` 或高于 `highThresh` 的像素置 0，区间内的像素置 `maxval`。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄 |
| lowThresh | Double | 是 | 低阈值（0~255） |
| highThresh | Double | 是 | 高阈值（0~255，需 >= lowThresh） |
| maxval | Double | 是 | 区间内像素值（一般为 255） |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄，失败返回 `""` |

### 自适应二值化

#### matAdaptiveThreshold(matId, maxValue, adaptiveMethod, thresholdType, blockSize, c)

根据每个像素邻域的局部特性自动计算阈值，对光照不均、背景渐变的图像效果更好。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄 |
| maxValue | Double | 是 | 最大值（一般为 255） |
| adaptiveMethod | Int | 是 | 自适应方法：0 = 邻域均值(MEAN\_C)，1 = 邻域高斯加权(GAUSSIAN\_C) |
| thresholdType | Int | 是 | 二值化类型：0 = BINARY，1 = BINARY\_INV |
| blockSize | Int | 是 | 邻域块大小（必须为正奇数，如 3、5、7） |
| c | Double | 是 | 从均值/加权均值减去的常数，通常 2~15 |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄，失败返回 `""` |

### 颜色空间转换

#### getHSV(matId, type)

获取 HSV 图像或其中一种通道图像。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄 |
| type | Int | 是 | -1 表示 HSV 图像，0 表示 H 通道，1 表示 S 通道，2 表示 V 通道 |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄，失败返回 `""` |

**示例：**

```lua
local hsvMat = opcvOps.getHSV(srcMat, -1)  -- 完整 HSV 图
local hMat   = opcvOps.getHSV(srcMat, 0)   -- H 通道（色相）
local sMat   = opcvOps.getHSV(srcMat, 1)   -- S 通道（饱和度）
local vMat   = opcvOps.getHSV(srcMat, 2)   -- V 通道（明暗）
```

#### getHLS(matId, type)

获取 HLS 图像或其中一种通道图像。注意 HLS 与 HSV 的明度/饱和度通道顺序不同。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄 |
| type | Int | 是 | -1 表示 HLS 图像，0 表示 H 通道，1 表示 L 通道，2 表示 S 通道 |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄，失败返回 `""` |

#### getBGR(matId, type)

获取 BGR 图像或其中一种通道图像。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄 |
| type | Int | 是 | -1 表示 BGR 图像，0 表示 B 通道，1 表示 G 通道，2 表示 R 通道 |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄，失败返回 `""` |

### 边缘/轮廓检测

#### findCannys(matId, threshold1, threshold2, apertureSize, L2gradient)

Canny 边缘检测，输入通常为灰度图，输出二值边缘图。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（灰度图） |
| threshold1 | Double | 是 | 弱阈值（默认 50） |
| threshold2 | Double | 是 | 强阈值（默认 100） |
| apertureSize | Int | 是 | Sobel 算子大小（默认 3，可为 3、5、7） |
| L2gradient | Boolean | 是 | 是否使用更精确的 L2 范数（默认 false） |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄（单通道边缘图），失败返回 `""` |

### 形状检测

#### findLines(matId, src\_multiple, rho, theta, threshold, minLineLength, maxLineGap, weakThreshold, strongThreshold)

直线检测（内部先做 Canny 边缘检测，再做 HoughLinesP）。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（灰度图） |
| src\_multiple | Double | 是 | 缩放比例（默认 1.0） |
| rho | Int | 是 | 步长（像素，默认 1） |
| theta | Int | 是 | 角度（度，默认 1；如 90 只检测水平和竖直的线） |
| threshold | Int | 是 | 连续检测到多少个 rho 点认为是一条直线（默认 10） |
| minLineLength | Int | 是 | 最小线段长度（默认 50） |
| maxLineGap | Int | 是 | 两直线间缺多少像素仍认为是同一条直线（默认 5） |
| weakThreshold | Int | 是 | Canny 弱阈值（默认 50） |
| strongThreshold | Int | 是 | Canny 强阈值（默认 100） |

| 返回值类型 | 说明 |
|-----------|------|
| String | JSON 数组，如 `[[x1,y1,x2,y2],...]`，失败返回 `""` |

**示例：**

```lua
-- 每隔 1 度检测一次
local lines = opcvOps.findLines(srcMat, 1.0, 1, 1, 10, 50, 10, 50, 100)
print(lines)  -- [[x1,y1,x2,y2],...]
```

#### findCircles(matId, minDist, accuracy, minRadius, maxRadius, cannyThreshold, dp)

圆形检测（HoughCircles 霍夫圆变换）。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（灰度图） |
| minDist | Double | 是 | 圆心之间最小距离，解决同心圆问题 |
| accuracy | Double | 是 | 找圆精度 0~1.0，越接近 1 越像圆 |
| minRadius | Int | 是 | 最小半径 |
| maxRadius | Int | 是 | 最大半径 |
| cannyThreshold | Double | 否 | Canny 强阈值（默认 100） |
| dp | Double | 否 | 累加器分辨率（默认 1.5） |

| 返回值类型 | 说明 |
|-----------|------|
| String | JSON 数组，如 `[[x,y,r],...]`，失败返回 `""` |

**示例：**

```lua
local circles = opcvOps.findCircles(srcMat, 10, 0.95, 5, 100, 100, 1.5)
print(circles)  -- [[圆心x,圆心y,半径],...]
```

#### findPolygons(matId, Angles, compareMode, minArea, maxArea, mode, method, epsilon)

多边形检测（三角形、矩形、五边形、多边形、圆等凸包形状）。

对二值图做轮廓检测后，按目标角数与面积筛选，返回符合条件的轮廓索引数组。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（二值化图像或轮廓） |
| Angles | Int | 是 | 目标角数/边数，如三角形为 3、五边形为 5 |
| compareMode | Int | 否 | 比较方式：-1 小于 Angles，0 等于 Angles，1 大于 Angles（默认 0） |
| minArea | Double | 否 | 目标最小面积（默认 100） |
| maxArea | Double | 否 | 目标最大面积（默认 -1 表示无上限） |
| mode | Int | 否 | 轮廓检索模式（0、1、2，默认 0） |
| method | Int | 否 | 轮廓近似方法（1、2，默认 2） |
| epsilon | Double | 否 | 轮廓近似逼近阈值（默认 -1 表示目标周长的百分之一） |

| 返回值类型 | 说明 |
|-----------|------|
| String | JSON 整数数组（轮廓索引），失败返回 `""` |

**示例：**

```lua
-- 检测三角形
local triIndex = opcvOps.findPolygons(binaryMat, 3, 0, 100, -1, 0, 2, -1)
if triIndex ~= "" then
    local triContours = opcvOps.getContours(binaryMat, 0, 2, triIndex, 1, 8)
end
-- 检测圆（大于 10 边）
local circleIndex = opcvOps.findPolygons(binaryMat, 10, 1, 100, -1, 0, 2, -1)
```

### 凸包

#### getConvexHull(matId, mode, method, contoursIndex, thickness, lineType)

凸包（以不凹陷的方式围绕轮廓画折线）。对二值图做轮廓检测，为选中的每个轮廓计算凸包并绘制到黑色画布上。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（二值化图像或轮廓） |
| mode | Int | 否 | 轮廓检索模式（0、1、2，默认 0） |
| method | Int | 否 | 轮廓近似方法（1、2，默认 2） |
| contoursIndex | String | 否 | 要绘制凸包的轮廓索引数组，默认空字符串表示全部，如 `"[1,3,5]"` |
| thickness | Int | 否 | 线条宽度，-1 表示填充（默认 1） |
| lineType | Int | 否 | 线条类型：8 不抗锯齿，16 抗锯齿（默认 8） |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄（凸包形状图片），失败返回 `""` |

**示例：**

```lua
local hull = opcvOps.getConvexHull(srcMat, 0, 2, "", 2, 16)
```

#### isContourConvex(matId, mode, method, contoursIndex, epsilon)

判断轮廓是否为凸包（轮廓是否凸），返回布尔数组。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（二值化图像或轮廓） |
| mode | Int | 否 | 轮廓检索模式（0、1、2，默认 0） |
| method | Int | 否 | 轮廓近似方法（1、2，默认 2） |
| contoursIndex | String | 否 | 要判断的轮廓索引数组，默认空字符串表示全部 |
| epsilon | Int | 否 | 轮廓近似逼近阈值（默认 -1 表示目标周长的百分之一） |

| 返回值类型 | 说明 |
|-----------|------|


### 轮廓处理

> 以下轮廓接口的 `mode` 与 `method` 语义一致：
>
> * **mode**：0 只检测最外围轮廓（内围忽略）；1 检测所有轮廓但不建等级；2 检测所有轮廓并建立两级等级（外围为顶层）
> * **method**：1 保存边界所有连续点；2 仅保存拐点（拐点间直线段信息点不保留）
>
> `contoursIndex` 用于筛选轮廓。只要 mode 和 method 一样，各轮廓函数返回的数组是一一对应的，如 `轮廓重心[5]` 与 `轮廓长度[5]` 是同一个轮廓的信息。

#### getContours(matId, mode, method, contoursIndex, thickness, lineType)

二值化图轮廓提取/绘制。把选中的轮廓绘制到黑色画布上，返回画好的图片。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（二值图） |
| mode | Int | 否 | 轮廓检索模式（0、1、2，默认 0） |
| method | Int | 否 | 轮廓近似方法（1、2，默认 2） |
| contoursIndex | String | 否 | 要绘制的轮廓索引数组，默认空字符串表示全部 |
| thickness | Int | 否 | 线条宽度，-1 表示填充（默认 1） |
| lineType | Int | 否 | 线条类型：8 不抗锯齿，16 抗锯齿（默认 8） |

| 返回值类型 | 说明 |
|-----------|------|
| String | 新 Mat 句柄（轮廓图片），失败返回 `""` |

**示例：**

```lua
local allContours = opcvOps.getContours(binaryMat, 0, 2, "", 1, 8)     -- 全部轮廓
local twoContours = opcvOps.getContours(binaryMat, 2, 2, "[1,7]", 1, 8) -- 第 1、7 个轮廓
local filled      = opcvOps.getContours(binaryMat, 2, 2, "[1,7]", -1, 8) -- 填充第 1、7 个
```

#### getContoursRect(matId, mode, method, contoursIndex)

获取轮廓的外接矩形（boundingRect）。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（二值图） |
| mode | Int | 否 | 轮廓检索模式（0、1、2，默认 0） |
| method | Int | 否 | 轮廓近似方法（1、2，默认 2） |
| contoursIndex | String | 否 | 轮廓索引数组，默认空字符串表示全部 |

| 返回值类型 | 说明 |
|-----------|------|
| String | JSON 对象数组，如 `[{"left":x,"top":y,"right":x+w,"bottom":y+h,"width":w,"height":h,"fill":f},...]`，其中 `fill` 为轮廓填充率（轮廓面积/外接矩形面积，0~1），失败返回 `""` |

> **提示**：`fill` 可用来区分图案类型——实心色块 fill 接近 1，镂空/音符图案 fill 较低（约 0.3~0.7）。

#### getContoursCircles(matId, mode, method, contoursIndex)

获取轮廓的外接圆形（minEnclosingCircle）。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| matId | String | 是 | 输入 Mat 句柄（二值图） |
| mode | Int | 否 | 轮廓检索模式（0、1、2，默认 0） |
| method | Int | 否 | 轮廓近似方法（1、2，默认 2） |
| contoursIndex | String | 否 | 轮廓索引数组，默认空字符串表示全部 |

| 返回值类型 | 说明 |
|-----------|------|
| String | JSON 二维数组，如 `[[x,y,r],...]`，失败返回 `""` |

#### filter2D(matId, kernelType, ddepth, anchorX, anchorY, delta, borderType)

## OOP 例子

演示了如何根据 CPU 架构，加载指定的 ABI 插件包（体积比全架构小很多）。

```lua
-- 懒人精灵高级版
import('com.nx.assist.lua.LuaEngine')

-- 获取 CPU 架构名称
local function getCpuArchName()
    local arch = getCpuArch()
    if arch == 0 then
        return 'x86'
    elseif arch == 1 then
        return 'armeabi-v7a'
    elseif arch == 2 then
        return 'arm64-v8a'
    elseif arch == 3 then
        return 'x86_64'
    end
end

-- 加载 XfxPlugin.lua 类
local xfxModule = require('lib/XfxPlugin')

-- 创建 XFX 对象实例
local XFX = xfxModule:new({
    apkName = 'xfxPlugin-release' .. '-' .. getCpuArchName() ..'.apk',  -- 加载指定CPU架构的 APK 文件名
    context = LuaEngine.getContext(), -- 插件的全局上下文
})

---------------------------------------------------------------------------------------------------------------------

-- 引入图像识别类
local opcvOps = XFX:getOps('opencvOps'); assert(opcvOps)

-- 懒人精灵高级版截图
local bmp = LuaEngine.snapShot(0, 0, 0, 0)
local srcMat = opcvOps.bitmapToMat(bmp)   -- 统一转换入口

local grayMat = opcvOps.matToGray(srcMat)                                      -- 灰度，返回Mat句柄
local thresholdMat = opcvOps.matThreshold(grayMat, 127, 255, 0)                -- BINARY 二值化
local dbThresholdMat = opcvOps.matDoubleThreshold(grayMat, 100, 200, 255)      -- 双阈值二值化（保留 100~200 亮度区间的像素）
local adaptiveMat = opcvOps.matAdaptiveThreshold(grayMat, 255, 1, 0, 15, 10)   -- 高斯加权自适应二值化，块大小 15，常数 10

-- 保存
local path = '/sdcard/Download/opencvTest/'
print('保存灰度图',opcvOps.saveMat(grayMat, path .. "gray.png"))
print('保存二值化图',opcvOps.saveMat(thresholdMat, path .. "threshold.png"))
print('保存双阈值图',opcvOps.saveMat(dbThresholdMat, path .. "dbThreshold.png"))
print('保存自适应图',opcvOps.saveMat(adaptiveMat, path .. "adaptive.png"))

-- 回收方式一：逐个回收
print('回收原Mat图',opcvOps.recycle(srcMat))
print('回收灰度图',opcvOps.recycle(grayMat))
print('回收二值化图',opcvOps.recycle(thresholdMat))
print('回收双阈值图',opcvOps.recycle(dbThresholdMat))
print('回收自适应图',opcvOps.recycle(adaptiveMat))

-- 回收方式二：清空全部Mat句柄
opcvOps.clearMats()
```

## 性能优化策略

### 1. 链式复用 Mat 句柄

处理链路全程用 Mat 句柄传递，避免每次重新转 Bitmap：

```lua
local srcMat = opcvOps.bitmapToMat(bmp)
local grayMat = opcvOps.matToGray(srcMat)
local resultMat = opcvOps.matThreshold(grayMat, 127, 255, 0)
opcvOps.recycle(srcMat)
opcvOps.recycle(grayMat)
opcvOps.recycle(resultMat)
```

### 2. 及时释放

* 每个 Mat 句柄用完即 `recycle`
* 脚本结束时调用 `clearMats()` 释放全部
* 循环处理时每轮产生的 Mat 及时回收

### 3. 算法选择

| 场景 | 推荐 |
| --- | --- |
| 光照均匀的固定阈值分割 | `matThreshold`（BINARY） |
| 光照不均、背景渐变 | `matAdaptiveThreshold` |
| 提取固定亮度区间 | `matDoubleThreshold` |
| 前景亮度不确定 | `matThreshold`（OTSU，type=8） |
| 颜色目标提取 | `getHSV` + `inRange` + `copyTo` |
| 凸包形状识别 | `findPolygons` + `getContours` |

## 错误处理机制

图像接口（返回 Mat 句柄）通过判空处理异常：

```lua
local resultMat = opcvOps.matToGray(srcMat)
if resultMat ~= nil and resultMat ~= "" then
    -- 成功，resultMat 为灰度句柄
else
    -- 失败，可能是句柄不存在、native 库未加载、参数非法
end
```

数组接口（返回 JSON）通过判空处理异常：

```lua
local areas = opcvOps.getContoursArea(binaryMat, 0, 2, "")
if areas ~= nil and areas ~= "" then
    -- 成功，areas 为 JSON 数组
end
```

**防御性编程建议：**

1. 每次调用后判断返回值是否为 `""` 或 `nil`
2. `matAdaptiveThreshold` 的 `blockSize` 必须为正奇数，否则返回 `""`
3. `matDoubleThreshold` 的 `lowThresh` 必须 <= `highThresh`
4. 轮廓接口的 `contoursIndex` 默认传空字符串 `""` 表示全部
5. Mat 句柄使用完毕后务必 `recycle` 释放
