# EmailOps\_邮件发送

## 模块简介

`EmailOps` 提供 SMTP 邮件发送能力，支持纯文本、HTML、附件与异步发送。

邮件通过插件内 SMTP 直连发送，不会调起系统邮件 App。

## 功能概览

* **SMTP 配置**：按配置名保存、判断、删除、清空 SMTP 配置
* **SMTP 探测**：验证配置能否连接并登录 SMTP，也可发送测试邮件验证投递链路
* **多配置发送**：可保存多个配置名，例如 `qq`、`work`、`notice`，发送时用 `configName` 选择
* **邮件发送**：发送纯文本、HTML、附件邮件
* **异步发送**：创建任务、查询状态、取消未完成任务
* **地址校验**：校验单个邮箱或邮箱数组
* **错误处理**：统一返回 JSON，并可读取最近一次错误码和错误消息

## 数据格式约定

收件人、抄送、密送、回复地址支持两种格式：

```lua
-- 单个邮箱，直接传字符串
'target@example.com'

-- 多个邮箱
{
  'target@example.com',
  'copy@example.com'
}
```

插件也兼容如下格式，但常规发送不需要填写 `name`。

```json
{"email":"target@example.com","name":"收件人"}
```

文件附件支持两种格式，附件名会自动取文件名，MIME 类型会按文件名自动识别：

```lua
-- 单个附件，直接传路径
'/sdcard/report.txt'

-- 多个附件
{
  '/sdcard/report.txt',
  '/sdcard/log.txt'
}
```

不需要传列表时请显式传入 `[]`。

`sendMail` 还支持直接传入截图或图片处理得到的 `Bitmap`：

```lua
-- 单个 Bitmap 附件
bmp

-- 多个 Bitmap 附件
{ bmp1, bmp2 }

-- 多个 Bitmap 附件，并指定附件文件名
[
  { img = bmp1, name = '首页' },
  { img = bmp2, name = '装备页' }
]
```

Bitmap 附件会按 PNG 格式写入临时文件再发送，邮件发送结束后自动删除临时文件。

异步发送接口 `sendMailAsync` 仍使用附件路径或附件路径 JSON。

### configSmtp()

保存 SMTP 配置。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| configName | String | 是 | 配置名称，用于区分多个邮箱配置 |
| host | String | 是 | SMTP 服务器地址 |
| port | Int | 是 | SMTP 端口，如 SSL 常用 465、STARTTLS 常用 587 |
| username | String | 是 | SMTP 用户名 |
| password | String | 是 | SMTP 密码或授权码 |
| fromEmail | String | 是 | 发件人邮箱 |
| fromName | String | 是 | 发件人显示名，不需要时传空字符串 |
| security | String | 是 | `SSL`、`STARTTLS`、`NONE` |
| enableAuth | Boolean | 是 | 是否启用 SMTP 认证 |
| connectionTimeoutMs | Int | 是 | 连接超时毫秒，小于等于 0 使用默认值 |
| readTimeoutMs | Int | 是 | 读取超时毫秒，小于等于 0 使用默认值 |

| 返回值类型 | 说明 |
|-----------|------|
| Boolean | 保存成功返回 true，参数错误返回 false |

#### security 参数说明

SMTP 连接的加密方式：

| 值 | 说明 | 常见端口 |
| --- | --- | --- |
| `SSL` | 连接一开始就使用 SSL/TLS 加密 | 465 |
| `STARTTLS` | 先普通连接，再升级为 TLS 加密 | 587 |
| `NONE` | 不启用连接加密，通常只适合内网或测试服务 | 25 |

常见邮箱服务商一般使用 `SSL + 465` 或 `STARTTLS + 587`。如果不确定，优先看邮箱服务商的 SMTP 设置说明。

`configSmtp` 只保存配置并检查参数格式，不会连接服务器，也不会验证授权码。需要验证配置是否真实可用时，请调用 `testSmtpLogin()` 或 `sendTestMail()`。

### sendText()

发送邮件正文，支持纯文本与 HTML。正文中若包含 HTML 标签（如 `<div>`、`</p>`、`<br/>` 等），插件会按 HTML 发送，否则按纯文本发送，无需手动指定。

简单版：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| configName | String | 是 | SMTP 配置名称 |
| toJson | String | 是 | 单个收件人邮箱或邮箱 JSON 数组 |
| subject | String | 是 | 邮件主题 |
| text | String | 是 | 邮件正文，纯文本或 HTML |

完整参数版：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| configName | String | 是 | SMTP 配置名称 |
| toJson | String | 是 | 单个收件人邮箱或邮箱 JSON 数组 |
| ccJson | String | 是 | 抄送邮箱或邮箱 JSON 数组，不需要时传 `[]` |
| bccJson | String | 是 | 密送邮箱或邮箱 JSON 数组，不需要时传 `[]` |
| subject | String | 是 | 邮件主题 |
| text | String | 是 | 邮件正文，纯文本或 HTML |
| replyToJson | String | 是 | 回复邮箱或邮箱 JSON 数组，不需要时传 `[]` |

| 返回值类型 | 说明 |
|-----------|------|
| String | 发送结果 JSON 字符串 |

发送 HTML 邮件示例：

```lua
local result = emailOps.sendText(
  'qq',
  'target@example.com',
  '[]',
  '[]',
  'HTML邮件',
  '<h3>你好</h3><p>这是一封 HTML 邮件。</p>',
  '[]'
)
```

### sendMail()

发送完整邮件，可携带附件。正文中若包含 HTML 标签（如 `<div>`、`</p>`、`<br/>` 等），插件会按 HTML 发送，否则按纯文本发送，无需手动指定。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| configName | String | 是 | SMTP 配置名称 |
| toJson | String | 是 | 单个收件人邮箱或邮箱 JSON 数组 |
| subject | String | 是 | 邮件主题 |
| body | String | 是 | 邮件正文，纯文本或 HTML |
| attachmentJson | String | 是 | 单个附件路径、附件路径 JSON 数组或 `[]` |

完整参数版本可额外传 `ccJson`、`bccJson`、`replyToJson`，不需要时传 `[]`。

| 返回值类型 | 说明 |
|-----------|------|
| String | 发送结果 JSON 字符串 |

返回 JSON 字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | Boolean | 是否发送成功 |
| code | Int | 结果码，`0` 表示成功，其他值见错误码 |
| message | String | 结果说明或错误原因 |
| messageId | String | 邮件服务器返回的消息 ID，成功时可能存在 |
| elapsedMs | Int | 本次调用耗时毫秒 |

成功示例：

```json
{"success":true,"code":0,"message":"success","messageId":"xxx","elapsedMs":1234}
```

失败示例：

```json
{"success":false,"code":1004,"message":"SMTP认证失败","elapsedMs":120}
```

#### Bitmap 附件重载

当附件来自截图、裁剪、图片处理等 Bitmap 对象时，可以直接使用 Bitmap 重载，不需要先手动保存到文件。

发送完成后，需要手动销毁 Bitmap 资源。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| attachmentBitmap | Bitmap | 是 | 单个 Bitmap 附件，不能为空且不能已回收 |
| attachmentBitmaps | Bitmap\[] | 是 | Bitmap 数组，例如 `{bmp1, bmp2}`，元素不能为空且不能已回收 |
| attachmentItems | Object\[] | 是 | Bitmap 配置数组，例如 `[{img=bmp1,name='首页'}]`，`img` 为图片对象，`name` 为附件名 |

未指定名称时，图片附件会以 `img_1.png`、`img_2.png` 这样的文件名加入邮件，MIME 类型为 `image/png`。

使用 `attachmentItems` 时，`name` 不需要写 `.png` 后缀，插件会自动补齐。例如 `name='首页'` 会作为 `首页.png` 发送。

### sendMailAsync()

异步发送完整邮件。`taskId` 传空字符串时自动生成。正文中若包含 HTML 标签，插件会按 HTML 发送，否则按纯文本发送，无需手动指定。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| configName | String | 是 | SMTP 配置名称 |
| taskId | String | 是 | 任务 ID，传空字符串自动生成 |
| toJson | String | 是 | 单个收件人邮箱或邮箱 JSON 数组 |
| subject | String | 是 | 邮件主题 |
| body | String | 是 | 邮件正文，纯文本或 HTML |
| attachmentJson | String | 是 | 单个附件路径、附件路径 JSON 数组或 `[]` |

完整参数版本可额外传 `ccJson`、`bccJson`、`replyToJson`，不需要时传 `[]`。

| 返回值类型 | 说明 |
|-----------|------|
| String | 任务创建结果 JSON，包含 `taskId` 和 `status` |

返回 JSON 字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | Boolean | 任务是否创建成功 |
| code | Int | 结果码，`0` 表示任务创建成功 |
| message | String | 结果说明或错误原因 |
| taskId | String | 异步任务 ID |
| status | String | 创建成功时为 `pending` |
| elapsedMs | Int | 创建任务耗时，通常为 `0` |

成功示例：

```json
{"success":true,"code":0,"message":"task created","elapsedMs":0,"taskId":"mail-001","status":"pending"}
```

失败示例：

```json
{"success":false,"code":1001,"message":"taskId 已存在: mail-001","elapsedMs":0,"taskId":"mail-001"}
```

### getTaskStatus()

查询异步发送任务状态。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| taskId | String | 是 | 任务 ID |

| 返回值类型 | 说明 |
|-----------|------|
| String | 任务状态 JSON，`status` 为 `pending`、`running`、`success`、`failed`、`cancelled` 或 `missing` |

返回 JSON 字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | Boolean | 邮件任务是否最终成功；执行中、失败、取消、缺失均为 false |
| code | Int | 结果码，`0` 表示发送成功，`1008` 表示任务不存在 |
| message | String | 当前任务说明或发送结果说明 |
| taskId | String | 任务 ID |
| status | String | `pending`、`running`、`success`、`failed`、`cancelled` 或 `missing` |
| createdAtMs | Long | 任务创建时间戳，毫秒 |
| messageId | String | 邮件服务器返回的消息 ID，成功时可能存在 |
| elapsedMs | Int | 发送耗时毫秒 |

等待执行示例：

```json
{"success":false,"code":1006,"message":"任务等待执行","elapsedMs":0,"taskId":"mail-001","status":"pending","createdAtMs":1785260000000}
```

执行中示例：

```json
{"success":false,"code":1006,"message":"任务执行中","elapsedMs":0,"taskId":"mail-001","status":"running","createdAtMs":1785260000000}
```

成功示例：

```json
{"success":true,"code":0,"message":"success","messageId":"xxx","elapsedMs":1234,"taskId":"mail-001","status":"success","createdAtMs":1785260000000}
```

失败示例：

```json
{"success":false,"code":1002,"message":"SMTP 配置不存在: qq","elapsedMs":1,"taskId":"mail-001","status":"failed","createdAtMs":1785260000000}
```

任务不存在示例：

```json
{"success":false,"code":1008,"message":"任务不存在: mail-404","elapsedMs":0,"taskId":"mail-404","status":"missing"}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| taskId | String | 是 | 任务 ID |

| 返回值类型 | 说明 |
|-----------|------|
| Boolean | 成功发起取消返回 true，任务不存在或任务已结束返回 false |

### validateAddresses()

校验邮箱地址格式，可用于发送前检查单个邮箱或邮箱数组。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| addressJson | String | 是 | 单个邮箱、邮箱 JSON 数组，或带 `email`/`name` 的对象 JSON |

| 返回值类型 | 说明 |
|-----------|------|
| String | 校验结果 JSON 字符串 |

成功示例：


```json

```

### getLastResult()

| 返回值类型 | 说明 |
|-----------|------|
| String | 最近一次同步或异步发送产生的结果 JSON 字符串；尚未发送时返回默认失败 JSON |

### getLastErrorCode()

获取最近一次错误码。

| 返回值类型 | 说明 |
|-----------|------|
| Int | `0` 表示最近一次关键操作没有错误，其他值见错误码 |

```lua
print(emailOps.getLastErrorCode())
```

#### 错误码

| 错误码 | 说明 |
|--------|------|

| 1001 | 参数错误 |
| 1002 | 配置不存在 |
| 1003 | 附件不存在 |
| 1004 | SMTP 认证失败 |
| 1005 | 连接失败 |

### getLastErrorMessage()

获取最近一次错误消息。

| 返回值类型 | 说明 |
|-----------|------|
| String | 没有错误时返回空字符串 |


## 完整 Lua 示例

### 保存多个 SMTP 配置

```lua
import('com.nx.assist.lua.LuaEngine')

local loader = LuaEngine.loadApk('/sdcard/plugins/xfx/xfxPlugin-release.apk')
local UtilsMain = loader.loadClass('com.xfx.plugin.UtilsMain')
UtilsMain.init(LuaEngine.getContext())

local emailOps = UtilsMain.emailOps()

local ok1 = emailOps.configSmtp(
  'qq',
  'smtp.qq.com',
  465,
  'your@qq.com',
  '授权码或密码',
  'your@qq.com',
  'XFX机器人',
  'SSL',
  true,
  15000,
  30000
)

local ok2 = emailOps.configSmtp(
  'work',
  'smtp.example.com',
  587,
  'notice@example.com',
  'password',
  'notice@example.com',
  '通知服务',
  'STARTTLS',
  true,
  15000,
  30000
)

if not ok1 or not ok2 then
  print(emailOps.getLastErrorMessage())
  return
end
```

```lua
-- 发送截图到指定邮箱
-- recipientEmail: 收件人邮箱地址
-- 返回: true=发送成功, false=失败

  if not recipientEmail or recipientEmail == "" then
    print("⚠️ 收件邮箱为空，跳过发送")
    return false
  end

  local bmp = LuaEngine.snapShot(0, 0, 0, 0)
  if not bmp then

  end

  local subject = "XTNZ 胜利战利品截图 " .. timeStr
  local body = "胜利战利品截图，发送时间: " .. timeStr

  local result = emailOps.sendMail(
```

## 注意事项

* `configSmtp` 可保存多组配置，后续所有发送方法都通过 `configName` 选择使用哪组配置。
* `configSmtp` 不会进行网络探测；需要验证 SMTP 授权码或连接可用性时调用 `testSmtpLogin`。
* `sendTestMail` 会真实发送一封测试邮件，可能受到邮箱服务商频率限制。
* SMTP 授权码通常不是邮箱登录密码，请按邮箱服务商要求生成。
* 同步发送会阻塞当前调用线程，脚本场景推荐使用 `sendMailAsync`。
* 附件路径必须是安卓设备上可读取的本地文件路径。
* Bitmap 附件发送前必须先调用 `UtilsMain.init(context)`，插件需要使用缓存目录保存临时 PNG。
* Bitmap 配置数组中的 `name` 会作为邮件附件名；未带 `.png` 后缀时会自动补齐。
* 多收件人、多附件请用 Lua table 再 `jsonLib.encode`，单个邮箱或单个附件可直接传字符串。
