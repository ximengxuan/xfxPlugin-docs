模块简介 ​

模块简介 ​

OpencvOps 提供常用图像预处理能力，是插件内推荐的图片连续处理主链路。

  • 系统要求：Android 7.0+（minSdk 24）

全局策略 ​

  • 需要连续处理、识别、找图、轮廓、阈值、形态学、相似度比较时，优先把 Bitmap 或文件转成 Mat 句柄，后续全部使用 OpencvOps。
  • ImageOps 保留为 Bitmap 工具箱，适合图片读取、保存、Base64/bytes、相册、EXIF、简单水印、圆形/圆角和临时 Bitmap 处理。
  • ImageOps.scale() / compare() / gray() / crop() / clone() 继续兼容旧脚本，但新文档和新 demo 推荐迁移到 OpencvOps.scale() / compare() / gray() / crop() / clone()。

推荐主路径：

lua
local opcvOps = UtilsMain.opencvOps()

local bmp = LuaEngine.snapShot(0, 0, 0, 0)
local mat = opcvOps.bitmapToMat(bmp)
local copy = opcvOps.clone(mat)
local small = opcvOps.scale(copy, 0.5, 0.5)
local sim = opcvOps.compare(mat, small, "avgHash")

opcvOps.recycle(mat)
opcvOps.recycle(copy)
opcvOps.recycle(small)

功能概览 ​

  • 统一转换：bitmapToMat(bitmap) —— Bitmap 转 Mat 句柄（入口）
  • 格式转换：matToBase64(matId, format, quality) / base64ToMat(base64) —— Mat 与 Base64 字符串互转
  • 读取文件：readResMat(path) —— 从图片文件读取为 Mat
  • 尺寸查询：getWidth(matId) / getHeight(matId) —— 获取 Mat 宽高
  • 克隆：clone(matId) —— 深拷贝 Mat，返回新的独立 Mat 句柄
  • 灰度处理：gray(matId) —— 彩色图转单通道灰度图
  • 二值化处理：threshold(matId, thresh, maxval, type) —— 固定阈值二值化
  • 双阈值二值化：doubleThreshold(matId, lowThresh, highThresh, maxval) —— 区间保留二值化
  • 自适应二值化：adaptiveThreshold(matId, maxValue, adaptiveMethod, thresholdType, blockSize, c) —— 局部自适应二值化
  • 颜色空间转换：getHSV(matId, type) / getHLS(matId, type) / getBGR(matId, type) —— 全图或单通道
  • 像素平均值：getBGRAverage(matId, type) —— 获取 BGR 各通道像素平均值
  • 边缘检测：findCannys(matId, threshold1, threshold2, apertureSize, L2gradient) —— Canny 边缘检测
  • 形状检测：findLines / findCircles / findPolygons（二值图轻量入口）/ findPolygonsEx（任意图增强入口） —— 直线 / 圆 / 凸包形状检测
  • 凸包：getConvexHull / isContourConvex
  • 轮廓处理：getContours / getContoursRect / getContoursCircles / getContoursLength / getContoursArea / getContoursHierarchy / getContoursMoments
  • 形态学操作：dilate / erode / open / close / topHat / blackHat / gradient / skeleton
  • 滤波 / 像素运算：absDiff / bitwiseOr / medianBlur / gaussianBlur / blur / bilateral / filter2D
  • 颜色范围 / 掩膜：inRange / copyTo
  • 区域操作：crop（裁剪） / drawRect / drawRects（画框） / findImg（模板匹配找图）
  • 屏幕标记：drawPointShow / drawRectShow / drawCircleShow / drawImageShow / drawMarksShow —— 异步悬浮绘制检测结果
  • 图片美化：clip / addTextWatermark / addImageWatermark / round / compress
  • 梯度形状匹配：loadYaml / matchGradientShape / releaseYaml / getYamlNames
  • 几何变换：warpPerspective（透视变换）
  • 投影与计数：projection / projectionValue（行 / 列投影）/ projectionMean（行 / 列平均亮度）/ countNonZero / countNonZeroRect（非零像素计数）
  • 保存：save(matId, path) / save(matId, filePath, format, quality) / saveToAlbum(matId, format, quality) —— Mat 句柄保存为图片文件或相册
  • 回收：recycle(matId) / clear() —— 释放 Mat 池内存
  • 回收校验：isRecycled(matId) —— 判断 Mat 句柄是否已回收

返回约定 ​

  • 返回 String 的匹配类接口返回 JSON 字符串，成功时 code 为 0。
  • 返回 String 的句柄类接口失败时返回 ""，成功时返回形如 mat_1 的 Mat 句柄。
  • 返回 Int 的计数类接口失败时返回 -1。
