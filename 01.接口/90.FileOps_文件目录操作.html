模块简介 ​

FileOps 提供常用文件/目录操作：创建、读写、重命名、复制/移动、删除、大小/行数/MD5、路径工具，以及目录/文件信息的 JSON 列举。

功能概览 ​

  • 基础读写：读取/写入字符串/字节数组，创建文件/目录，追加内容
  • 属性与信息：存在性、文件/目录判断，名称/扩展名/行数/大小/MD5/文件信息
  • 操作：重命名、复制、移动、删除（文件/目录/目录内全部/按扩展名删除）
  • 路径与子目录：尾斜杠修饰、路径连接、子目录判断、是否有子目录、目录是否为空
  • 目录列举：按扩展名或直接子项输出 JSON

API 接口列表 ​

1. 基础读写与创建 ​

create() ​

根据路径自动创建文件或目录（已存在也返回 true）。 优先检查路径是否已存在且是目录，如果是则保持为目录。 否则根据路径是否有扩展名来判断创建文件还是目录。

参数名类型必填说明
pathString?是文件或目录路径
返回值类型说明
Boolean创建或已存在返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.create("/sdcard/demo"))
print(FileOps.create("/sdcard/demo/a.txt"))

write() ​

将字符串写入文件（覆盖写入）。

参数名类型必填说明
filePathString是文件路径
contentString是写入内容
返回值类型说明
Boolean成功返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.write("/sdcard/demo/a.txt", "hello"))

writeBytes() ​

将字节数组写入文件（覆盖写入，自动创建父目录）。

参数名类型必填说明
filePathString?是文件路径
bytesByteArray?是要写入的字节数组
返回值类型说明
Boolean成功返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
-- 注意：Lua 中需要将字符串转换为字节数组

append() ​

将文本追加到文件末尾，如果文件不存在则创建。

参数名类型必填说明
filePathString?是文件路径
textString?是要追加的文本
encodingString否字符编码，默认为 UTF-8
返回值类型说明
Boolean成功返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.append("/sdcard/demo/a.txt", "world\n"))
print(FileOps.append("/sdcard/demo/a.txt", "中文", "UTF-8"))

appendBytes() ​

将字节数组追加到文件末尾，如果文件不存在则创建。

参数名类型必填说明
filePathString?是文件路径
bytesByteArray?是要追加的字节数组
返回值类型说明
Boolean成功返回 true

示例：

lua

-- 注意：Lua 中需要将字符串转换为字节数组

read() ​

读取文件内容为字符串。

参数名类型必填说明
filePathString是文件路径
返回值类型说明
String?文件内容或 null

示例：

参数名类型必填说明

3. 操作（重命名/复制/移动/删除） ​

rename() ​

重命名文件或目录。

参数名类型必填说明
filePathString?是原路径
newNameString?是新文件名
返回值类型说明
Boolean成功返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.rename("/sdcard/demo/a.txt", "b.txt"))

copy() ​

复制文件。

参数名类型必填说明
srcPathString是源
destPathString是目标
返回值类型说明
Boolean成功返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.copy("/sdcard/demo/b.txt", "/sdcard/demo/b_copy.txt"))

move() ​

移动文件。

参数名类型必填说明
srcPathString是源
destPathString是目标
返回值类型说明
Boolean成功返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.move("/sdcard/demo/b_copy2.txt", "/sdcard/demo2/b_copy2.txt"))

delete() ​

删除单个文件或目录。 如果是目录，会递归删除目录下的所有文件和子目录。

参数名类型必填说明
pathString是路径
返回值类型说明
Boolean成功返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.delete("/sdcard/demo2/b_copy2.txt"))

deleteFile() - 按扩展名删除 ​

删除目录下指定后缀的文件（只删除文件，不删除子目录）。

参数名类型必填说明
dirPathString?是目录路径
extensionsJsonString?是JSON 数组字符串，包含要删除的文件扩展名（如 ["txt","js"] ）
返回值类型说明
Int删除的文件数量，失败返回 -1，无匹配文件返回 0

示例：

lua
local FileOps = UtilsMain.fileOps()
-- 删除目录下所有 .txt 和 .js 文件
local count = FileOps.deleteFile("/sdcard/demo", jsonLib.encode({"txt","js"}))
print("删除了 " .. count .. " 个文件")

clearDir() ​

清空目录。

参数名类型必填说明
dirPathString?是目录
返回值类型说明
Boolean成功返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.clearDir("/sdcard/demo2"))

4. 路径与子目录 ​

ensurePath() ​

补全路径末尾斜杠。

参数名类型必填说明
pathString?否路径
返回值类型说明
String?末尾带斜杠路径

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.ensurePath("/sdcard/demo"))

isSubDirExists() ​

判断目录中是否存在指定子目录。

参数名类型必填说明
dirPathString?是目录
subDirNameString?是子目录名
返回值类型说明
Boolean存在返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.isSubDirExists("/sdcard", "demo"))

hasSubDirs() ​

判断目录是否存在子目录。

参数名类型必填说明
dirPathString?是目录
返回值类型说明
Boolean有子目录返回 true

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.hasSubDirs("/sdcard"))

isEmptyDir() ​

判断目录是否为空。如果路径不是目录，则返回 false。

参数名类型必填说明
dirPathString?是目录路径
返回值类型说明
Boolean如果是空目录返回 true，否则返回 false

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.isEmptyDir("/sdcard/demo"))

join() ​

连接两个路径。自动处理路径分隔符，确保结果路径格式正确。

参数名类型必填说明
basePathString?是基础路径
relativePathString?是相对路径
返回值类型说明
String连接后的完整路径

示例：

lua
local FileOps = UtilsMain.fileOps()
print(FileOps.join("/sdcard/demo", "a.txt"))
print(FileOps.join("/sdcard/demo/", "/a.txt"))

返回值类型说明

includeFilesBoolean是是否包含文件
返回值类型说明
StringJSON 数组字符串

lua
local xfxModule = require('lib/XfxPlugin')
local XFX = xfxModule:new({apkName = 'xfxPlugin-release.apk'})

local FileOps = XFX:getOps('fileOps')

local timestamp = TimeOps.getNowString()
local logEntry = '[' .. timestamp .. '] 这是一条日志记录\n'

-- 读取现有内容并追加
local existingContent = FileOps.read(logFile) or ''
FileOps.write(logFile, existingContent .. logEntry)

print('日志已记录')

示例 2：配置文件读写 ​

lua
local xfxModule = require('lib/XfxPlugin')
local XFX = xfxModule:new({apkName = 'xfxPlugin-release.apk'})

local FileOps = XFX:getOps('fileOps')
if not FileOps then
    print('无法获取 FileOps 对象')
    return
end

local configPath = '/sdcard/app_config.json'

-- 读取配置
if FileOps.isExists(configPath) then
    local configContent = FileOps.read(configPath)
    print('配置内容: ' .. configContent)
    -- 解析 JSON（需要 jsonLib）
    local config = jsonLib.decode(configContent)
    print(config)
    
    FileOps.delete(configPath)
else
    -- 创建默认配置
    local defaultConfig = '{"version": "1.0", "enabled": true}'
    FileOps.write(configPath, defaultConfig)
    print('已创建默认配置')
end

示例 3：文件备份 ​

lua
local xfxModule = require('lib/XfxPlugin')
local XFX = xfxModule:new({apkName = 'xfxPlugin-release.apk'})

local FileOps = XFX:getOps('fileOps')
local TimeOps = XFX:getOps('timeOps')

if not FileOps or not TimeOps then
    print('无法获取必要的 Ops 对象')
    return
end

local sourceFile = '/sdcard/important_data.txt'
local backupDir = '/sdcard/backups/'

-- 确保备份文件和目录存在
FileOps.create(sourceFile)
FileOps.create(backupDir)

if FileOps.isExists(sourceFile) then
    -- 生成备份文件名（带时间戳）
    local timestamp = TimeOps.getNowString('yyyyMMddHHmmss')
    local backupFile = backupDir .. 'backup_' .. timestamp .. '.txt'
    
    -- 复制文件
    local success = FileOps.copy(sourceFile, backupFile)
    if success then
        print('备份成功: ' .. backupFile)
    else
        print('备份失败')
    end
else
    print('源文件不存在')
end

示例 5：文件完整性校验 ​

lua
local xfxModule = require('lib/XfxPlugin')
local XFX = xfxModule:new({apkName = 'xfxPlugin-release.apk'})

local FileOps = XFX:getOps('fileOps')
local EncryptOps = XFX:getOps('encryptOps')

if not FileOps or not EncryptOps then
    print('无法获取必要的 Ops 对象')
    return
end

local filePath = '/sdcard/important_file.txt'
local md5File = filePath .. '.md5'

-- 计算文件 MD5
if FileOps.isExists(filePath) then
    local currentMD5 = FileOps.md5(filePath)
    print('文件 MD5: ' .. currentMD5)

    -- 保存 MD5
    FileOps.write(md5File, currentMD5)

    -- 验证文件完整性
    sleep(1000)
    local newMD5 = FileOps.md5(filePath)
    local storedMD5 = FileOps.read(md5File)

    if newMD5 == storedMD5 then
        print('文件完整性验证通过')
    else
        print('警告：文件可能已被修改！')
    end
else
    print('文件不存在')
end

注意事项 ​

  1. 文件路径：

    • 使用绝对路径，如 "/sdcard/file.txt"
    • 确保路径中的文件和目录存在
    • 路径区分大小写

  2. 权限要求：

    • 读写外部存储需要相应权限
    • 某些系统目录可能需要特殊权限
    • 建议使用应用私有目录或 SD 卡

  3. 文件编码：

    • 默认使用 UTF-8 编码
    • 读取文件时注意编码问题
    • 二进制文件需要使用其他方法

  4. 文件删除：

    • 删除操作不可恢复
    • 删除前建议先备份重要文件
    • 删除目录会删除目录下所有内容

  5. JSON 格式：

    • listDir() 返回 JSON 数组字符串
    • 每个元素包含：fileName, filePath, lastModified, size
    • 需要使用 jsonLib 解析 JSON

  6. 目录操作：

    • 目录路径建议以 "/" 结尾
    • 可以使用 ensurePath() 确保路径格式正确

  7. 文件 MD5：

    • 大文件 MD5 计算可能需要较长时间
    • 建议在后台线程计算
    • MD5 用于文件完整性校验

  8. 错误处理：

    • 文件不存在时某些操作可能返回 false 或 null
    • 建议使用 isExists() 先检查
    • Lua可使用 pcall() 捕获可能的异常
