SpeechToTextOps_语音转文字 ​

模块简介 ​

SpeechToTextOps 提供轻量级语音文件转文字（STT）能力，简称 STT。

离线模型不内置到 APK。需要离线识别时，请把模型下载并解压到外部目录，例如 /sdcard/xfx_stt_models/sherpa-ncnn-xxx，再调用 initOffline(engine, modelDir, optionsJson)。

功能概览 ​

  • 统一返回结构：所有识别入口都返回 code/message/elapsedMs/data JSON。
  • system 后端：检查系统识别服务，支持麦克风实时识别；文件识别会尝试系统音频源 URI，不支持时返回统一错误。
  • cloud 后端：支持 generic HTTP，包含 multipart/form-data 和 JSON Base64 两种模式。
  • offline 后端：当前 APK 已接入 sherpa-ncnn arm64 runtime；vosk、sherpa-onnx、whisper-cpp 仍为预留，模型必须外置。
  • 音频预处理：支持读取音频信息和转码为 16k 单声道 WAV。
  • 异步回调：异步识别完成后更新 getLastResult() 并触发 setResultCallback()。

后端对比 ​

后端当前状态优点限制
system已接入不需要配置服务端，适合麦克风实时识别Android 系统识别器对“音频文件输入”支持不一致；不支持时请转码后走 cloud/offline
cloud已接入 generic体积增量接近 0，服务端模型可灵活替换需要网络与服务端接口，不要硬编码真实密钥
offlinesherpa-ncnn 已接入，其他 runtime 预留可无网运行，模型外置不增加 APK 主包体积需要外置模型目录；Android 10 读取公共 /sdcard 目录需授予存储读取权限

注意事项 ​

  • 系统兼容性：系统 SpeechRecognizer 标准能力主要面向麦克风实时识别。文件输入依赖系统识别服务是否支持音频源 URI，不支持时请转码后走 cloud/offline。
  • 音频格式：建议先用 convertToWav(input, output, 16000, 1) 转为 16k 单声道 WAV，便于服务端和离线后端处理。
  • 文件路径：优先使用普通可读写文件路径。Android 13+ 如遇 URI 或媒体库权限问题，可结合 UriOps 处理。
  • 网络与密钥：不要在代码或文档中硬编码真实密钥；推荐从外部配置读取后调用 setCloudConfig()。
  • 耗时行为：同步识别会阻塞当前线程；长音频或网络请求建议用异步接口。
