EmailOps_邮件发送 ​

模块简介 ​

EmailOps 提供 SMTP 邮件发送能力，支持纯文本、HTML、附件与异步发送。

功能概览 ​

  • SMTP 配置：按配置名保存、判断、删除、清空 SMTP 配置
  • SMTP 探测：验证配置能否连接并登录 SMTP，也可发送测试邮件验证投递链路
  • 多配置发送：可保存多个配置名，例如 qq、work、notice，发送时用 configName 选择
  • 邮件发送：发送纯文本、HTML、附件邮件
  • 异步发送：创建任务、查询状态、取消未完成任务
  • 地址校验：校验单个邮箱或邮箱数组
  • 错误处理：统一返回 JSON，并可读取最近一次错误码和错误消息

数据格式约定 ​

收件人、抄送、密送、回复地址支持两种格式：

lua
-- 单个邮箱，直接传字符串
'target@example.com'

-- 多个邮箱

  'target@example.com',
  'copy@example.com'
}

API 接口列表 ​

configSmtp() ​

保存 SMTP 配置。

参数名类型必填说明
configNameString是配置名称，用于区分多个邮箱配置
hostString是SMTP 服务器地址
portInt是SMTP 端口，如 SSL 常用 465、STARTTLS 常用 587
usernameString是SMTP 用户名
passwordString是SMTP 密码或授权码
fromEmailString是发件人邮箱
fromNameString是发件人显示名，不需要时传空字符串
securityString是SSL、STARTTLS、NONE
enableAuthBoolean是是否启用 SMTP 认证
connectionTimeoutMsInt是连接超时毫秒，小于等于 0 使用默认值
readTimeoutMsInt是读取超时毫秒，小于等于 0 使用默认值
返回值类型说明
Boolean保存成功返回 true，参数错误返回 false

security 参数说明 ​

SMTP 连接的加密方式：

值说明常见端口
SSL连接一开始就使用 SSL/TLS 加密465
STARTTLS先普通连接，再升级为 TLS 加密587
NONE不启用连接加密，通常只适合内网或测试服务25

常见邮箱服务商一般使用 SSL + 465 或 STARTTLS + 587。如果不确定，优先看邮箱服务商的 SMTP 设置说明。

configSmtp 只保存配置并检查参数格式，不会连接服务器，也不会验证授权码。需要验证配置是否真实可用时，请调用 testSmtpLogin() 或 sendTestMail()。

hasConfig() ​

判断指定 SMTP 配置是否已经保存。

参数名类型必填说明
configNameString是配置名称
返回值类型说明
Boolean配置存在返回 true，否则返回 false

removeConfig() ​

删除指定 SMTP 配置。

参数名类型必填说明
configNameString是配置名称
返回值类型说明
Boolean删除成功返回 true，配置不存在返回 false

clearConfigs() ​

清空全部 SMTP 配置。

返回值类型说明
Boolean清空成功返回 true

testSmtpLogin() ​

探测指定 SMTP 配置是否可以连接并完成登录，不发送邮件。

参数名类型必填说明
configNameString是SMTP 配置名称
返回值类型说明
String探测结果 JSON 字符串

成功示例：

json
{"success":true,"code":0,"message":"success","elapsedMs":520}
1

失败示例：

json
{"success":false,"code":1004,"message":"AuthenticationFailedException: ...","elapsedMs":260}
1

sendTestMail() ​

发送一封纯文本测试邮件，验证 SMTP 配置、授权码、收件地址和邮件投递链路。

参数名类型必填说明
configNameString是SMTP 配置名称
toEmailString是接收测试邮件的邮箱地址
返回值类型说明
String发送结果 JSON 字符串，字段与 sendMail 相同

🔒 sendMail() ​

发送邮件正文，支持纯文本与 HTML。正文中若包含 HTML 标签（如 <div>、</p>、<br/> 等），插件会按 HTML 发送，否则按纯文本发送，无需手动指定。

简单版：

参数名类型必填说明
configNameString是SMTP 配置名称
toJsonString是单个收件人邮箱或邮箱 JSON 数组
subjectString是邮件主题
textString是邮件正文，纯文本或 HTML

完整参数版：

参数名类型必填说明
configNameString是SMTP 配置名称
toJsonString是单个收件人邮箱或邮箱 JSON 数组
ccJsonString是抄送邮箱或邮箱 JSON 数组，不需要时传 []
bccJsonString是密送邮箱或邮箱 JSON 数组，不需要时传 []
subjectString是邮件主题
textString是邮件正文，纯文本或 HTML
replyToJsonString是回复邮箱或邮箱 JSON 数组，不需要时传 []
返回值类型说明
String发送结果 JSON 字符串

发送 HTML 邮件示例：

lua
local result = emailOps.sendMail(
  'qq',
  'target@example.com',
  '[]',
  '[]',
  'HTML邮件',
  '<h3>你好</h3><p>这是一封 HTML 邮件。</p>',
  '[]'
)

🔒 sendMail() ​

发送完整邮件，可携带附件。

正文中若包含 HTML 标签（如 <div>、</p>、<br/> 等），插件会按 HTML 发送，否则按纯文本发送，无需手动指定。

参数名类型必填说明
configNameString是SMTP 配置名称
toJsonString是单个收件人邮箱或邮箱 JSON 数组
subjectString是邮件主题
bodyString是邮件正文，纯文本或 HTML
attachmentJsonString是单个附件路径、附件路径 JSON 数组或 []

完整参数版本可额外传 ccJson、bccJson、replyToJson，不需要时传 []。

返回值类型说明
String发送结果 JSON 字符串

返回 JSON 字段说明：

字段类型说明
successBoolean是否发送成功
codeInt结果码，0 表示成功，其他值见错误码
messageString结果说明或错误原因
messageIdString邮件服务器返回的消息 ID，成功时可能存在
elapsedMsInt本次调用耗时毫秒

成功示例：

json
{"success":true,"code":0,"message":"success","messageId":"xxx","elapsedMs":1234}
1

失败示例：

json
{"success":false,"code":1004,"message":"SMTP认证失败","elapsedMs":120}
1

Bitmap 附件重载 ​

当附件来自截图、裁剪、图片处理等 Bitmap 对象时，可以直接使用 Bitmap 重载，不需要先手动保存到文件。

发送完成后，需要手动销毁 Bitmap 资源。

参数名类型必填说明
attachmentBitmapBitmap是单个 Bitmap 附件，不能为空且不能已回收
attachmentBitmapsBitmap[]是Bitmap 数组，例如 {bmp1, bmp2}，元素不能为空且不能已回收
attachmentItemsObject[]是Bitmap 配置数组，例如 [{img=bmp1,name='首页'}]，img 为图片对象，name 为附件名

未指定名称时，图片附件会以 img_1.png、img_2.png 这样的文件名加入邮件。

使用 attachmentItems 时，name 不需要写 .png 后缀，插件会自动补齐。例如 name='首页' 会作为 首页.png 发送。

sendMailAsync() ​

异步发送完整邮件。

taskId 传空字符串时自动生成。

正文中若包含 HTML 标签，插件会按 HTML 发送，否则按纯文本发送，无需手动指定。

参数名类型必填说明
configNameString是SMTP 配置名称
taskIdString是任务 ID，传空字符串自动生成
toJsonString是单个收件人邮箱或邮箱 JSON 数组
subjectString是邮件主题
bodyString是邮件正文，纯文本或 HTML
attachmentJsonString是单个附件路径、附件路径 JSON 数组或 []

完整参数版本可额外传 ccJson、bccJson、replyToJson，不需要时传 []。

返回值类型说明
String任务创建结果 JSON，包含 taskId 和 status

返回 JSON 字段说明：

字段类型说明
successBoolean任务是否创建成功
codeInt结果码，0 表示任务创建成功
messageString结果说明或错误原因
taskIdString异步任务 ID
statusString创建成功时为 pending
elapsedMsInt创建任务耗时，通常为 0

成功示例：

json
{"success":true,"code":0,"message":"task created","elapsedMs":0,"taskId":"mail-001","status":"pending"}
1

失败示例：

json
{"success":false,"code":1001,"message":"taskId 已存在: mail-001","elapsedMs":0,"taskId":"mail-001"}
1

getTaskStatus() ​

查询异步发送任务状态。

参数名类型必填说明
taskIdString是任务 ID
返回值类型说明
String任务状态 JSON，status 为 pending、running、success、failed、cancelled 或 missing

返回 JSON 字段说明：

字段类型说明
successBoolean邮件任务是否最终成功；执行中、失败、取消、缺失均为 false
codeInt结果码，0 表示发送成功，1008 表示任务不存在
messageString当前任务说明或发送结果说明
taskIdString任务 ID
statusStringpending、running、success、failed、cancelled 或 missing
createdAtMsLong任务创建时间戳，毫秒
messageIdString邮件服务器返回的消息 ID，成功时可能存在
elapsedMsInt发送耗时毫秒

等待执行示例：

json
{"success":false,"code":1006,"message":"任务等待执行","elapsedMs":0,"taskId":"mail-001","status":"pending","createdAtMs":1785260000000}

执行中示例：

json
{"success":false,"code":1006,"message":"任务执行中","elapsedMs":0,"taskId":"mail-001","status":"running","createdAtMs":1785260000000}
1

失败示例：

getLastResult() ​

获取最近一次发送结果。

返回值类型说明
String最近一次同步或异步发送产生的结果 JSON 字符串；尚未发送时返回默认失败 JSON

getLastErrorCode() ​

获取最近一次错误码。

返回值类型说明
Int0 表示最近一次关键操作没有错误，其他值见错误码

示例：

lua
print(emailOps.getLastErrorCode())
1

错误码说明

1003附件不存在

1007超时
1008任务不存在

getLastErrorMessage() ​

获取最近一次错误消息。

返回值类型说明
String没有错误时返回空字符串

示例：

保存多个 SMTP 配置 ​

import('com.nx.assist.lua.LuaEngine')

local loader = LuaEngine.loadApk('/sdcard/plugins/xfx/xfxPlugin-release.apk')
local UtilsMain = loader.loadClass('com.xfx.plugin.UtilsMain')
UtilsMain.init(LuaEngine.getContext())

local emailOps = UtilsMain.emailOps()

local ok1 = emailOps.configSmtp(
  'qq',
  'smtp.qq.com',
  465,
  'your@qq.com',
  '授权码或密码',
  'your@qq.com',
  'XFX机器人',
  'SSL',
  true,
  15000,
  30000
)

local ok2 = emailOps.configSmtp(
  'work',
  'smtp.example.com',
  587,
  'notice@example.com',
  'password',
  'notice@example.com',
  '通知服务',
  'STARTTLS',
  true,
  15000,
  30000
)

if not ok1 or not ok2 then
  print(emailOps.getLastErrorMessage())
  return
end

lua

import('com.nx.assist.lua.LuaEngine')

-- 加载 XfxPlugin.lua 类
local xfxModule = require('lib/XfxPlugin')

-- 创建 XFX 对象实例
local XFX = xfxModule:new({
    apkName = 'xfxPlugin-release.apk',  -- APK 文件名
    context = LuaEngine.getContext(),  -- 上下文对象
})


local CONFIG_NAME = "qq"
local SENDER_EMAIL = "654321@qq.com"
local AUTH_CODE = "nshagcskwkdejhaa"

local emailOps = XFX:getOps('emailOps'); assert(emailOps)

-- 初始化SMTP配置 (QQ邮箱 SMTP SSL 465)
local ok = emailOps.configSmtp(
    CONFIG_NAME,
    "smtp.qq.com",
    465,
    SENDER_EMAIL,
    AUTH_CODE,
    SENDER_EMAIL,
    "小飞侠插件",
    "SSL",
    true,
    15000,
    30000
  )
if ok then
	print("📧 SMTP配置保存成功")
else
    print(emailOps.getLastErrorMessage(),emailOps.getLastErrorCode(),emailOps.getLastResult())
	print("⚠️ SMTP配置初始化失败")
end

-- 发送截图到指定邮箱
-- recipientEmail: 收件人邮箱地址
-- 返回: true=发送成功, false=失败
function 发送截图(recipientEmail)
  if not recipientEmail or recipientEmail == "" then
    print("⚠️ 收件邮箱为空，跳过发送")
    return false
  end

  local bmp = LuaEngine.snapShot(0, 0, 0, 0)
  if not bmp then
    print("⚠️ 截图失败，无法发送邮件")
    return false
  end

  -- 2. 构造邮件内容
  local timeStr = os.date("%Y-%m-%d %H:%M:%S")
  local subject = "XTNZ 胜利战利品截图 " .. timeStr
  local body = "胜利战利品截图，发送时间: " .. timeStr

  -- 3. 发送(Bitmap附件)
  print('开始同步发送邮件...')
  local result = emailOps.sendMail(
    CONFIG_NAME,
    recipientEmail,
    subject,
    body,
    { bmp }
  )
  print('邮件发送结果: ' .. tostring(result))

  -- 4. 销毁截图资源(无论成败都销毁)
  LuaEngine.releaseBmp(bmp)

  -- 5. 解析结果
  local data = jsonLib.decode(result)
  if data and data.success then
    print("📧 胜利截图已发送到: " .. recipientEmail)
    return true
  else
    print("⚠️ 邮件发送失败: " .. tostring(data and data.message or result))
    print(emailOps.getLastErrorMessage(),emailOps.getLastErrorCode(),emailOps.getLastResult())

    return false
  end
end

注意事项 ​

  • sendMail 属于高级接口，调用前需通过 LicenseOps 完成授权初始化与校验。
  • configSmtp 可保存多组配置，后续所有发送方法都通过 configName 选择使用哪组配置。
  • configSmtp 不会进行网络探测；需要验证 SMTP 授权码或连接可用性时调用 testSmtpLogin。
  • sendTestMail 会真实发送一封测试邮件，可能受到邮箱服务商频率限制。
  • SMTP 授权码通常不是邮箱登录密码，请按邮箱服务商要求生成。
  • 同步发送会阻塞当前调用线程，生产场景推荐使用异步 sendMailAsync。
  • 附件路径必须是安卓设备上可读取的本地文件路径。
  • Bitmap 配置数组中的 name 会作为邮件附件名；未带 .png 后缀时会自动补齐。

QQ 邮箱 SMTP 授权码获取 ​

⚠️重要：授权码只会生成时显示一次，不能直接查看旧授权码，忘记只能重新生成新的。

PC网页版操作（必须浏览器网页，QQ邮箱APP不能生成授权码） ​

  1. 登录QQ邮箱
  2. 点右上角【设置】→【账号与安全】→【安全设置】
  3. 找到：POP3/IMAP/SMTP/Exchange/CardDAV 服务
  • 需要先绑定手机号
  • 开启：POP3/SMTP服务（SMTP发送邮件就靠这个开关）
  1. 点击“生成授权码” → 短信验证 → 得到16位授权码，立刻复制保存，关掉页面就看不到了。
