# 更新日志

## 2026-08-06&#x20;

* 修复：`opcvOps.recycle(srcMat)`报错，去掉多参；
* 优化：`opencvOps`类，增加`isRecycled`方法；
* 更新：`opencvOps`类文档，补充 OOP 例子；
* 新增：大量`opencvOps`类图像处理接口；

## 2026-08-05&#x20;

* 新增：`OpencvOps` 图像处理类（官方 OpenCV 4.5.3 Java API）。
* 新增：`FtpOps` FTP / FTPS 文件上传下载管理类。
* 变更：`EmailOps` 移除 `sendHtml` 接口；`sendText`/`sendMail`/`sendMailAsync` 全部移除 `isHtml` 参数，改为自动判断正文是否包含 HTML 标签，决定按 HTML 或纯文本发送。
* 新增：`RegexOps.isHtml(input)`，判断字符串是否包含 HTML 标签。

## 2026-08-04&#x20;

* 新增：`ShapeMatchOps` 多边形检测接口，支持在 Bitmap 或图片文件中查找矩形。

## 2026-08-03&#x20;

* 修复：`paddleOcrOps`初始化时加载 V5 模型失败的问题；

## 2026-07-28&#x20;

* 新增：`EmailOps` 邮件发送类，支持多 SMTP 配置、纯文本/HTML/附件邮件、异步发送、任务状态查询和邮箱地址校验；

## 2026-07-16

* `TimeOps`新增时区设置接口，默认统一采用北京时间。
* `AppOps`新增安装、卸载、root判断、获取信息等接口。

## 2026-07-15&#x20;

* 修复：`YoloOps.initFromDir` 目录内多套模型时误选短文件的问题；`status()` 增加实际加载的 labels/bin/param 路径方便排查问题；
* 新增：`YoloOps.initFromDir(modelPath, targetSize, useGpu)`，按目录自动发现模型文件并初始化

## 2026-07-14

* 新增：`PaddleOcrOps.initFromDir(modelDirPath)`，按目录自动发现模型文件并初始化
* 新增：`snapShotByShell`
* 新增：`snapShotByScrcpy`
* 新增：`snapShot`

## 2026-07-13

* 新增：`RandomOps` 随机生成类，封装昵称与姓名生成接口

## 2026-07-08

* 新增：`NetworkOps.getPublicIPAddress(timeoutMillis)`，通过外网服务查询公网 IP 地址
* 新增：`HashSetOps` 集合类，支持多实例 HashSet 管理（添加/移除/包含判断/批量导入/JSON 导出）
* 新增：`HashMapOps` 映射类，支持多实例 HashMap 管理（存取/键值判断/批量导入/JSON 导出）

## 2026-07-07

* 新增：`AppOps.getAppName()`，根据包名获取已安装应用的显示名称
* 新增：`AppOps.getPackageName()`，根据应用名称获取包名
* 优化：`PaddleOcrOps.init(version)` 支持内置模型版本 `v4` / `v5` / `v6`（忽略大小写），默认使用 v6
* 新增：内置 PP-OCRv6 mobile NCNN 模型（`ppocrv6`）
* 新增：`PaddleOcrOps.getDefaultModelDir(version)`，获取指定版本模型释放目录
* 新增：`PaddleOcrOps.getLoadedVersion()`，查询当前已加载的内置模型版本
* 优化：`PaddleOcrOps.status()` 返回值增加 `modelVersion` 字段

## 2026-06-03

* 新增：`imgOps.clone(bmp)`方法；

## 2026-06-02

* 修改: `jaroWinklerSimilarity`接口为`jaroWinklerSim`
* 新增：`hmDistance`接口，计算两个字符串的汉明距离
* 新增： `imgOps.compare()` 接口，比较两个图片的相似度

## 2026-06-01

* 增加：PaddleOCR 识别类，支持默认模型和自定义 NCNN 模型

## 2026-05-28&#x20;
