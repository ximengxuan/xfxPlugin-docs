K歌滑块识别 ​

演示如何用 OpencvOps 接口实现"K歌滑块识别"。

采用极简泛化方案：不依赖模板匹配，只用轮廓几何特征锁定滑块。

  • 核心接口（仅 4 个）：getHSV / matThreshold / erode / getContoursRect
  • 画框标记（可选）：drawRect / saveMat

算法思路（4 步） ​

K歌滑块的特征：音符图案接近正方形、内部有音符空隙（填充率非满），且位于右侧滑轨区。

  1. 取 V 通道（明暗）反向二值化：暗色前景置白（阈值70）
  2. 3x3 矩形腐蚀：去噪、断开杂散连接
  3. 轮廓外接矩形：遍历所有轮廓
  4. 几何特征筛选：
    • 需在滑块区右侧（left > w，w = 75/300*图宽）
    • 宽度不超过滑块区（width <= w）
    • 面积不低于下限（minArea = 400/90000*图宽*图高）
    • 宽高比接近方形（0.7 <= w/h <= 1.4）——排除横向大色块与竖条
    • 填充率适中（0.28 <= fill <= 0.70）——排除实心装饰图与空心线框；音符内部有空隙

Lua 示例 ​

lua
-- K歌滑块极简定位（仅轮廓几何特征，无需模板匹配）
local UtilsMain = loader.loadClass('com.xfx.plugin.UtilsMain')
UtilsMain.init(LuaEngine.getContext())

-- 引入图像识别类
-- local opcvOps = XFX:getOps('opencvOps'); assert(opcvOps)
local opcvOps = UtilsMain.opencvOps()

local path = '/sdcard/Download/opencvTest/'

-- 1. 读取图片（或 LuaEngine.snapShot 截图）
local kgImg = opcvOps.readResMat("/sdcard/Download/插件实例/K歌滑块实例_img_1.png")
if kgImg == "" then print("读取图片失败"); return end

-- 2. V 通道（明暗）+ 反向二值化
local kg_V = opcvOps.getHSV(kgImg, 2)
print('保存V通道图',opcvOps.saveMat(kg_V, path .. "K歌滑块_V通道图.png"))

local binInv = opcvOps.matThreshold(kg_V, 70, 255, 1)   -- type=1 表示 BINARY_INV
print('保存反向二值化图',opcvOps.saveMat(binInv, path .. "K歌滑块_反向二值化图.png"))

-- 3. 3x3 矩形腐蚀（structType=0 矩形, 3x3, 锚点中心, 迭代1）
local eroded = opcvOps.erode(binInv, 0, 3, 3, -1, -1, 1)
print('保存腐蚀图',opcvOps.saveMat(eroded, path .. "K歌滑块_腐蚀图.png"))

-- 4. 轮廓外接矩形（mode=1 RETR_LIST, method=2 SIMPLE）
local rects = jsonLib.decode(opcvOps.getContoursRect(eroded, 1, 2, ""))
-- print('外接矩形',rects)

-- 5. 几何特征筛选
local W = opcvOps.getWidth(kgImg)
local H = opcvOps.getHeight(kgImg)
local w = 75 / 300 * W                    -- 滑块区宽度
local minArea = 400 / (300 * 300) * (W * H) -- 最小面积

local sliderRect = nil
for i = 0, #rects - 1 do
    local r = rects[i + 1]
    local rw, rh = r.right - r.left, r.bottom - r.top
    local area = rw * rh
    if r.left > w                       -- 滑块区右侧
       and rw <= w                       -- 宽度不超
       and area >= minArea               -- 面积够大
       and rw / rh >= 0.7 and rw / rh <= 1.4  -- 接近方形
       and r.fill >= 0.28 and r.fill <= 0.70  -- 音符空隙（填充率适中）
    then
        sliderRect = r
        break
    end
end

if sliderRect then
    print(string.format("找到滑块 rect=(%d,%d,%d,%d)", sliderRect.left, sliderRect.top, sliderRect.right, sliderRect.bottom))
    -- 画红色框并保存（drawRect(matId, left, top, right, bottom)）
    local boxed = opcvOps.drawRect(kgImg, sliderRect.left, sliderRect.top, sliderRect.right, sliderRect.bottom)
    opcvOps.saveMat(boxed, path .. "K歌滑块识别结果.png")
else
    print("未找到滑块")
end

-- 6. 回收
opcvOps.clearMats()

说明 ​

  • getContoursRect 返回对象数组 [{left, top, right, bottom, width, height, fill}, ...]，其中 fill 为该轮廓填充率（轮廓面积 / 外接矩形面积）。
  • 该方案不依赖 findImg/copyTo/cropMat/getContours，步骤最少、可泛化。
  • 若图片分辨率不同，w 与 minArea 按图宽高缩放，可适配不同屏幕。
