模块简介 ​

ShapeMatchOps 提供 xfxYolo PC 端训练出的 OpenCV 风格 YAML 模板匹配能力，适合在安卓脚本中识别透明形状等目标。

功能概览 ​

  • 读取一个或多个 PC 端训练出的 .yaml
  • 支持 Bitmap 或图片文件路径作为输入
  • 支持全分辨率 shape_full_points / shape_full_features
  • 支持多 YAML、同 label 多模板、统一 NMS、单目标 max_instances
  • 返回 JSON 字符串，便于懒人精灵和 Lua 解析

matchImageFile ​

参数名类型必填说明
imagePathString是待匹配图片路径
yamlPathsJsonString是YAML 路径 JSON 数组，例如 ["/sdcard/yaml/方向轮盘.yaml"]
thresholdFloat是分数阈值，范围 0.0 到 1.0
countInt是每个 YAML/模板最多保留的候选数量，多 YAML 调用会按模板数扩展总上限
pyramidModeString是金字塔模式，建议 "4,8"
nmsFloat是NMS 阈值，建议 0.3
debugCandidatesBoolean是兼容参数，当前不会返回 debugCandidates

detectPolygonsImageFile / detectPolygonsBitmap ​

参数名类型必填说明
imagePathString图片路径接口必填待检测图片路径
bitmapBitmapBitmap 接口必填待检测截图 Bitmap
edgeCountInt是目标角数/边数，矩形传 4

minAreaFloat是最小面积，-1 表示不限制；头像框建议 100

approxEpsilonFloat是近似逼近阈值，-1 表示自动

metadata 支持 ​

字段说明
search_region搜索中心区域，支持 coordinate: center_ratio 和绝对坐标
max_instances单个 YAML 最多保留实例数
page_exclusive_group页面互斥分组
page_exclusive_priority页面互斥优先级，优先级最高的分组会保留
min_edge_score最低边缘分量
min_orientation_score最低方向分量
negative_regions中心点落入后丢弃的负区域
score_boost最终分数加成
score_penalty最终分数惩罚

默认兼容规则覆盖：金币/钱袋、方向轮盘、盾牌、泉水/双剑、学习技能/加号、普攻/攻击剑、返回、关闭。

从 YAML 路径进行模板匹配 ​

lua

import('com.nx.assist.lua.LuaEngine')

-- 加载 XfxPlugin.lua 类
local xfxModule = require('lib/XfxPlugin')

-- 创建 XFX 对象实例
local XFX = xfxModule:new({
    apkName = 'xfxPlugin-release.apk',  -- APK 文件名
    context = LuaEngine.getContext(),  -- 上下文对象

local opcvOps = XFX:getOps('shapeMatchOps'); assert(opcvOps)

local imagePath = '/sdcard/Download/测试大图/adb_20260705_182651_1783247211115_0001.png'
local yamlDirPath = '/sdcard/Download/模板小图/yaml/'

---- 目录写法：推荐，自动读取目录下全部 yaml
local result = opcvOps.matchImageFileFromYamlDir(imagePath, yamlDirPath, 0.6, 16, '4,8', 0.3, false)

---- 写法一
-- local yamlPathsJson = '["/sdcard/Download/模板小图/yaml/方向轮盘.yaml","/sdcard/Download/模板小图/yaml/盾牌.yaml"]'
-- local result = opcvOps.matchImageFile(imagePath, yamlPathsJson, 0.6, 10, '4,8', 0.3, true)

---- 写法二

Steam账号切换：检测头像框 ​

lua
import('com.nx.assist.lua.LuaEngine')

local xfxModule = require('lib/XfxPlugin')
local XFX = xfxModule:new({
    apkName = 'xfxPlugin-release.apk',
    context = LuaEngine.getContext(),
})

local shapeOps = XFX:getOps('shapeMatchOps'); assert(shapeOps)
local imagePath = '/sdcard/Download/测试大图/截图_1785809395573.png'

-- 参数顺序：图片、角数、比较方式、搜索模式、轮廓近似、最小面积、最大面积、近似阈值
local result = shapeOps.detectPolygonsImageFile(imagePath, 4, 0, 0, 2, 100, -1, -1)
printEx(result)

local obj = jsonLib.decode(result)
if obj.code == 0 then
  for i, item in ipairs(obj.matches) do
    -- 头像框一般是左下角两个面积最大的四边形，再结合蓝色“已登录”文字判断另一个未登录账号。
    if item.left < 220 and item.top > 1600 and item.edgeCount == 4 then
      printEx('头像框 center=(' .. item.centerX .. ',' .. item.centerY .. ') area=' .. item.area)
    end
  end
else
  printEx(obj.message)
end

注意事项 ​

  • 推荐优先使用 matchImageFile 或新签名 matchBitmap，无需手动维护预加载状态。
  • 需要全目录识别时，优先使用 matchImageFileFromYamlDir 或 matchBitmapFromYamlDir，可减少脚本侧枚举和 JNI 往返。
  • yamlPathsJson 必须显式传入，即使只有一个 YAML 也使用 JSON 数组。
  • 当前安卓端复用轻量 native 匹配实现，已同步 metadata、全分辨率 shape 点、edge 粗筛、orientation 复核和 page exclusive 语义；与 PC 端 OpenCV/Numpy 的 matchTemplate 细节仍不完全逐像素一致。
  • 为获得更稳定性能，建议在 YAML metadata 中显式写入 search_region、max_instances、min_edge_score、min_orientation_score 和必要的 negative_regions。
