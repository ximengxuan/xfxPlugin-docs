拼图滑块验证码定位（腾讯防水墙） ​

演示如何用 OpencvOps 接口实现「拼图滑块验证码」的目标缺口定位。

适用场景 ​

图片中横向排列 3 个拼图形状（360x361 分辨率最常见）：

  • 最左：空心/浅色描边的「源拼图」（要拖动的滑块图案）
  • 中间 / 最右：深色填充拼图（其中之一是目标缺口）

算法自动判断源拼图与哪个深色拼图的缺口形状匹配，取匹配者作为目标，返回滑块需要拖动的水平像素距离。

算法思路（5 步极简泛化方案） ​

  1. 多阈值法收集候选：OTSU 正反 + 5 个固定阈值 + 3 个自适应阈值（共 14 种），找连通域，按位置去重保留最大
  2. 过滤尺寸 / 纵横比 / 填充率：排除 20~100 像素外的形状，排除太扁/太细的，过滤填充率 < 0.1 的空碎块
  3. 按宽度分桶聚类：5 像素一桶，取最频繁的桶作为 puzzle 宽度（puzzle 尺寸相近）
  4. Y 范围限制 + 等间距选 3 个：cy ∈ [80, 200]，cy 中位数对齐，按 cx 找 15% / 50% / 85% 三个候选
  5. 模板匹配确定目标：在源拼图区域取模板（TM_CCOEFF_NORMED），分别在中间和右侧区域搜索，取较高分者为目标

关键技巧——源拼图推断：当最左候选 fill > 0.5（看起来是深色实心），且 cx > 20% 宽，算法推断真正的源拼图应在 gap * 0.55 的左侧位置。这样即使源拼图轮廓过淡无法直接检测，也能定位。

单接口调用 ​

OpencvOps 提供了专用接口 findSliderTarget(matId)，一次调用即可获得滑动距离，无需自行拼装多步骤。

Lua 示例（推荐） ​

lua
local UtilsMain = loader.loadClass('com.xfx.plugin.UtilsMain')
UtilsMain.init(LuaEngine.getContext())

-- 引入图像识别类
local opcvOps = UtilsMain.opencvOps()
-- 或者：local opcvOps = XFX:getOps('opencvOps')

-- 1. 截图（懒人精灵全屏截图）
local bmp = LuaEngine.snapShot(0, 0, 0, 0)
local srcMat = opcvOps.bitmapToMat(bmp)
if srcMat == '' then print('截图失败'); return end

-- 2. 单接口调用：识别滑块目标位置
local json = opcvOps.findSliderTarget(srcMat)
local data = jsonLib.decode(json)

if data.error then
    print('识别失败: ' .. data.error)
    -- 失败时回退到手势识别或人工介入
else
    print(string.format('源拼图 中心: (%d, %d)', data.sourceCx, data.sourceCy))
    print(string.format('目标缺口中心: (%d, %d)', data.targetCx, data.targetCy))
    print(string.format('目标索引: %d (0=中间 / 1=右侧)', data.targetIndex))
    print(string.format('匹配分数: %.3f', data.bestMatchScore))
    print(string.format('源拼图是推断的: %s', tostring(data.sourceInferred)))
    print('===========================================')
    print('滑动距离: ' .. data.distance .. ' 像素')

    -- 3. 在原图上画框标注（可选）
    local path = '/sdcard/Download/opencvTest/'
    local s = data.source
    local boxed = opcvOps.drawRect(srcMat, s.x, s.y, s.x + s.w, s.y + s.h, '#FF0000', 2, false, true)
    local m = data.middle
    boxed = opcvOps.drawRect(boxed, m.x, m.y, m.x + m.w, m.y + m.h, '#00FFFF', 1, false, true)
    local r = data.right
    boxed = opcvOps.drawRect(boxed, r.x, r.y, r.x + r.w, r.y + r.h, '#FF00FF', 1, false, true)
    -- 画目标中心
    boxed = opcvOps.drawRect(boxed, data.targetCx - 5, data.targetCy - 5, data.targetCx + 5, data.targetCy + 5, '#00FF00', -1, false, true)
    opcvOps.saveMat(boxed, path .. 'sliderTarget.png')
    opcvOps.recycle(boxed)
end

-- 4. 回收（不调用 clearMats 也可，建议在脚本结束统一清理）
opcvOps.clearMats()

完整代码（画框标注 + 滑动距离应用） ​

lua
local UtilsMain = loader.loadClass('com.xfx.plugin.UtilsMain')
UtilsMain.init(LuaEngine.getContext())
local opcvOps = UtilsMain.opencvOps()
assert(opcvOps)

local saveDir = '/sdcard/Download/opencvTest/'

-- 截图（替换成自己的截图逻辑）
local bmp = LuaEngine.snapShot(0, 0, 0, 0)
local srcMat = opcvOps.bitmapToMat(bmp)
assert(srcMat ~= '')

-- 单接口：识别滑块目标
local json = opcvOps.findSliderTarget(srcMat)
local data = jsonLib.decode(json)

if data.error then
    print('[FAIL] ' .. data.error)
else
    print(string.format('[OK] src=(%d,%d) tgt=(%d,%d) distance=%d idx=%d score=%.3f',
        data.sourceCx, data.sourceCy, data.targetCx, data.targetCy,
        data.distance, data.targetIndex, data.bestMatchScore))

    -- 标注可视化
    local s = data.source
    local m = data.middle
    local r = data.right
    local vis = opcvOps.drawRect(srcMat, s.x, s.y, s.x + s.w, s.y + s.h, '#FF0000', 2, false, true)
    vis = opcvOps.drawRect(vis, m.x, m.y, m.x + m.w, m.y + m.h, '#00FFFF', 1, false, true)
    vis = opcvOps.drawRect(vis, r.x, r.y, r.x + r.w, r.y + r.h, '#FF00FF', 1, false, true)
    -- 画目标中心（绿色）
    vis = opcvOps.drawRect(vis, data.targetCx - 5, data.targetCy - 5, data.targetCx + 5, data.targetCy + 5, '#00FF00', -1, false, true)
    opcvOps.saveMat(vis, saveDir .. 'slider_result.png')
    opcvOps.recycle(vis)

    -- 应用滑动（伪代码，实际根据你使用的引擎 API）
    -- 例如：在指定位置向右滑动 distance 像素
    -- LuaEngine.gesture({from = {x1, y1}, to = {x1 + data.distance, y1}, duration = 800})
end

opcvOps.clearMats()

适用性说明 ​

  • 适配分辨率：360x361 是腾讯防水墙的常见大小，算法对此最优；其他分辨率只要保持宽高比且 puzzle 占图 30%~50% 高度也能工作
  • 适配光照：在 389 张腾讯防水墙样本（多种背景：山、海、桥、动物、城市等）上验证成功率约 99.7%
  • 不适用场景：
    • 拼图形状被大量水印 / 文字遮挡
    • 3 个拼图不在同一 Y 水平线
    • 拼图尺寸不在 20~100 像素范围（缩放过小的截图）
    • 出现更多拼图（>3 个）的变种验证码
  • 失败处理：接口返回 {"error":"..."}，建议回退到 K歌滑块识别（仅找右侧区域的方块）或人工接管

与其他滑块识别的对比 ​

接口用途复杂度
findSliderTarget拼图滑块验证码（腾讯防水墙等，3 puzzle）O(n) 候选筛选 + 2 次模板匹配
getContoursRect + 几何特征筛选（参考 117.OpencvOps_实例.md K歌示例）K歌音符滑块（1 puzzle）O(n) 候选筛选

调试小贴士 ​

如果识别失败，可以：

  1. 检查截图区域：确保 LuaEngine.snapShot 截图覆盖整个拼图验证码区域（包括背景图和 3 个 puzzle）
  2. 保存中间结果：用 opcvOps.saveMat 保存源图，送到 PC 上目视检查是否有 3 个 puzzle 在同一水平线
  3. 调整 Y 范围：如果你的拼图位置特殊（如很靠上 / 靠下），可能需要修改 Kotlin 中的 cy 范围 [80, 200]
  4. 查看目标索引：data.targetIndex 是 0 或 1，对应中间或右侧；可通过 data.middle / data.right 字段检查具体位置
  5. 多次截图：某些验证码会动态变化，建议间隔 100~300ms 多次截图取结果一致性最高者
