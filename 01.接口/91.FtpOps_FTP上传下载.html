模块简介 ​

FtpOps 是 FTP / FTPS 文件上传下载管理类的封装，基于 Apache Commons Net 实现。

支持 FTP（明文）与 FTPS（FTP over TLS），提供文件上传、下载、删除，目录创建、删除、重命名、列表浏览等常用管理功能。

功能概览 ​

  • 连接管理：FTP / FTPS 连接、断开、状态检查
  • 文件操作：上传、下载、删除
  • 目录操作：创建、删除、重命名、列目录、列文件、当前目录
  • 便捷封装：一次连接完成上传 / 下载并自动断开

使用流程 ​

连接(connect) → 上传/下载/目录操作 → 断开(disconnect)

连接为长连接会话，同一连接上可反复执行多个操作，最后调用 disconnect() 断开。

API 接口列表 ​

1. 连接管理 ​

connect() ​

连接 FTP / FTPS 服务器。

参数名类型必填说明
hostString是服务器主机名或 IP，如 ftp.example.com、192.168.1.100
portInt否端口号，默认 21（FTPS 隐式 TLS 常用 990）
usernameString是用户名
passwordString是密码
useFtpsBoolean否是否使用 FTPS（FTP over TLS），默认 false
implicitTlsBoolean否FTPS 时是否隐式 TLS（端口 990），默认 false（显式 TLS，端口 21）
passiveBoolean否是否被动模式，默认 true
binaryBoolean否是否二进制模式传输，默认 true
timeoutInt否连接超时（毫秒），默认 10000
返回值类型说明
String结果 JSON，格式：{"success": true, "host": "xxx", "port": 21}

示例：

lua
local ftpOps = UtilsMain.ftpOps()

-- 连接 FTP（明文）
local result = ftpOps.connect("ftp.example.com", 21, "user", "password")
print(result)

-- 连接 FTPS（显式 TLS）
local result = ftpOps.connect("ftp.example.com", 21, "user", "password", true)

isConnected() ​

检查是否已连接到 FTP 服务器。

返回值类型说明
String结果 JSON，格式：{"connected": true}

示例：

lua
local ftpOps = UtilsMain.ftpOps()
local info = jsonLib.parse(ftpOps.isConnected())
if info.connected then
    print("已连接")
else
    print("未连接")
end

disconnect() ​

断开 FTP 连接。

返回值类型说明
String结果 JSON，格式：{"success": true}

示例：

lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.disconnect()

2. 文件操作 ​

uploadFile() ​

上传本地文件到 FTP 服务器（自动创建远程目录）。

参数名类型必填说明
localFilePathString是本地文件绝对路径
remotePathString是FTP 服务器目标路径，如 /uploads/photo.jpg
返回值类型说明
String结果 JSON，格式：{"success": true, "remotePath": "/uploads/photo.jpg", "fileSize": 1234567}

示例：

lua
local ftpOps = UtilsMain.ftpOps()

-- 先连接
ftpOps.connect("ftp.example.com", 21, "user", "password")

-- 上传文件
local result = ftpOps.uploadFile(
    "/sdcard/Pictures/photo.jpg",   -- 本地文件
    "/uploads/images/photo.jpg"     -- 远程路径（自动创建 images 目录）
)
print(result)

local json = jsonLib.parse(result)
if json.success then
    print("上传成功，大小: " .. json.fileSize)
else
    print("上传失败: " .. json.error)
end

-- 断开
ftpOps.disconnect()

downloadFile() ​

从 FTP 服务器下载文件到本地。

参数名类型必填说明
remotePathString是FTP 服务器上的文件路径，如 /uploads/photo.jpg
saveDirString是本地保存目录
saveNameString否本地保存文件名，为 nil 时使用远程文件名
返回值类型说明
String结果 JSON，格式：{"success": true, "filePath": "/path/to/file", "fileSize": 1234567}

示例：

lua
local ftpOps = UtilsMain.ftpOps()

ftpOps.connect("ftp.example.com", 21, "user", "password")

-- 下载文件（自动使用远程文件名）
local result = ftpOps.downloadFile(
    "/uploads/images/photo.jpg",    -- 远程文件
    "/sdcard/Download"              -- 本地保存目录
)
print(result)

-- 指定保存文件名
local result = ftpOps.downloadFile(
    "/uploads/images/photo.jpg",
    "/sdcard/Download",
    "downloaded.jpg"
)

ftpOps.disconnect()

deleteFile() ​

删除 FTP 服务器上的文件。

参数名类型必填说明
remotePathString是FTP 服务器上的文件路径
返回值类型说明
String结果 JSON，格式：{"success": true}

示例：

lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.connect("ftp.example.com", 21, "user", "password")

local result = ftpOps.deleteFile("/uploads/images/old.jpg")
    print(result)
ftpOps.disconnect()

getFileInfo() ​

获取 FTP 服务器上文件的信息（大小、最后修改时间等）。

参数名类型必填说明
remotePathString是FTP 服务器上的文件路径，如 /uploads/photo.jpg
返回值类型说明
String结果 JSON，格式：{"success": true, "name": "photo.jpg", "path": "/uploads/photo.jpg", "size": 1234, "date": 1234567890123, "type": "file", "exists": true}

返回字段说明：

字段类型说明
successBoolean是否成功
existsBoolean文件是否存在
nameString文件名
pathString文件完整路径
sizeLong文件大小（字节）
dateLong最后修改时间（毫秒时间戳），无则返回 0
typeString类型：file / dir / unknown
lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.connect("ftp.example.com", 21, "user", "password")

-- 获取文件信息
local result = ftpOps.getFileInfo("/uploads/images/photo.jpg")
print(result)

local json = jsonLib.parse(result)
if json.success and json.exists then
    print("文件名: " .. json.name)
    print("大小: " .. json.size .. " bytes")
    local modTime = os.date("%Y-%m-%d %H:%M:%S", json.date / 1000)
    print("最后修改时间: " .. modTime)
else
    print("文件不存在")
end
ftpOps.disconnect()

3. 目录操作 ​

createDir() ​

创建 FTP 服务器目录（支持多级目录）。

参数名类型必填说明
remotePathString是远程目录路径，如 /uploads/images
返回值类型说明
String结果 JSON，格式：{"success": true, "path": "/uploads/images"}

示例：

lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.connect("ftp.example.com", 21, "user", "password")

local result = ftpOps.createDir("/uploads/images/2026")
print(result)
ftpOps.disconnect()

deleteDir() ​

删除 FTP 服务器上的空目录。

参数名类型必填说明
remotePathString是远程目录路径（必须为空）
返回值类型说明
String结果 JSON，格式：{"success": true}
lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.connect("ftp.example.com", 21, "user", "password")

-- 删除空目录
local result = ftpOps.deleteDir("/uploads/images/2026")
print(result)
ftpOps.disconnect()

rename() ​

重命名 FTP 服务器上的文件或目录。

参数名类型必填说明
fromString是原路径
toString是新路径
返回值类型说明
String结果 JSON，格式：{"success": true, "from": "xxx", "to": "xxx"}

示例：

lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.connect("ftp.example.com", 21, "user", "password")

local result = ftpOps.rename(
    "/uploads/photo.jpg",
    "/uploads/newphoto.jpg"
)
print(result)
ftpOps.disconnect()

listFiles() ​

列出 FTP 服务器指定目录下的所有文件。

参数名类型必填说明
remotePathString是远程目录路径，如 /uploads
返回值类型说明
String结果 JSON，格式：{"success": true, "files": [{"name":"a.jpg","size":1234,"date":123,"path":"/uploads/a.jpg"}]}

示例：

lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.connect("ftp.example.com", 21, "user", "password")

local result = ftpOps.listFiles("/uploads")
local json = jsonLib.parse(result)
if json.success then
    for i, f in ipairs(json.files) do
        print(f.name .. " (" .. f.size .. " bytes)")
    end
end
ftpOps.disconnect()

listDirs() ​

列出 FTP 服务器指定目录下的所有子目录。

参数名类型必填说明
remotePathString是远程目录路径，如 /uploads
返回值类型说明
String结果 JSON，格式：{"success": true, "dirs": ["/uploads/a", "/uploads/b"]}

示例：

lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.connect("ftp.example.com", 21, "user", "password")

local result = ftpOps.listDirs("/uploads")
local json = jsonLib.parse(result)
if json.success then
    for i, d in ipairs(json.dirs) do
        print(d)
    end
end
ftpOps.disconnect()

pwd() ​

获取 FTP 服务器当前工作目录。

返回值类型说明
String结果 JSON，格式：{"success": true, "path": "/"}

示例：

lua
local ftpOps = UtilsMain.ftpOps()
ftpOps.connect("ftp.example.com", 21, "user", "password")
print(ftpOps.pwd())
ftpOps.disconnect()

4. 便捷封装 ​

uploadFileOnce() ​

便捷上传：连接 FTP → 上传文件 → 自动断开。

参数名类型必填说明
hostString是服务器主机名或 IP
portInt是端口号
usernameString是用户名
passwordString是密码
localFilePathString是本地文件绝对路径
remotePathString是FTP 服务器目标路径
useFtpsBoolean否是否使用 FTPS，默认 false
timeoutInt否连接超时（毫秒），默认 10000
返回值类型说明
String结果 JSON，格式同 uploadFile()

示例：

lua
local ftpOps = UtilsMain.ftpOps()

-- 一次连接完成上传
local result = ftpOps.uploadFileOnce(
    "ftp.example.com",   -- 主机
    21,                  -- 端口
    "user",              -- 用户名
    "password",          -- 密码
    "/sdcard/test.jpg",  -- 本地文件
    "/uploads/test.jpg"  -- 远程路径
)
print(result)

downloadFileOnce() ​

便捷下载：连接 FTP → 下载文件 → 自动断开。

参数名类型必填说明
hostString是服务器主机名或 IP
portInt是端口号
usernameString是用户名
passwordString是密码
remotePathString是FTP 服务器上的文件路径
saveDirString是本地保存目录
saveNameString否本地保存文件名，为 nil 时使用远程文件名
useFtpsBoolean否是否使用 FTPS，默认 false
timeoutInt否连接超时（毫秒），默认 10000
返回值类型说明
String结果 JSON，格式同 downloadFile()

示例：

lua
local ftpOps = UtilsMain.ftpOps()

-- 一次连接完成下载
local result = ftpOps.downloadFileOnce(
    "ftp.example.com",   -- 主机
    21,                  -- 端口
    "user",              -- 用户名
    "password",          -- 密码
    "/uploads/test.jpg", -- 远程文件
    "/sdcard/Download",  -- 本地目录
    "test.jpg"           -- 保存文件名（可选）
)
print(result)

完整示例 ​

上传下载全流程 ​

lua
-- 导入必要的类
import('com.nx.assist.lua.LuaEngine')

-- 加载插件
local loader = LuaEngine.loadApk('xfxPlugin-release.apk')
local UtilsMain = loader.loadClass('com.xfx.plugin.UtilsMain')

-- 获取 FtpOps 实例
local ftpOps = UtilsMain.ftpOps()

-- 1. 连接 FTP 服务器
print("连接 FTP...")
local connResult = ftpOps.connect("ftp.example.com", 21, "user", "password")
local connJson = jsonLib.parse(connResult)
if not connJson.success then
    print("连接失败: " .. connJson.error)
    return
end

-- 2. 创建远程目录（自动创建多级）
ftpOps.createDir("/backup/2026")

-- 3. 上传文件
print("上传文件...")
local upResult = ftpOps.uploadFile("/sdcard/data.db", "/backup/2026/data.db")
print("上传结果: " .. upResult)

-- 4. 列出目录
print("列出远程目录...")
local listResult = ftpOps.listFiles("/backup/2026")
local listJson = jsonLib.parse(listResult)
if listJson.success then
    for i, f in ipairs(listJson.files) do
        print("  " .. f.name .. " (" .. f.size .. " bytes)")
    end
end

-- 5. 下载文件
print("下载文件...")
local downResult = ftpOps.downloadFile("/backup/2026/data.db", "/sdcard/restore")
print("下载结果: " .. downResult)

-- 6. 断开连接
ftpOps.disconnect()
print("完成！")

常见问题 ​

1. 连接失败 ​

  • 检查主机与端口：确认 FTP 服务器地址、端口正确（默认 21）
  • 检查账号密码：确认用户名密码正确
  • 检查网络：确认设备可以访问 FTP 服务器
  • FTPS 端口：隐式 TLS 通常使用 990 端口，需设置 implicitTls = true

2. 上传/下载失败 ​

  • 被动模式：服务器处于防火墙后时，建议使用被动模式（默认开启）。若被动模式失败，可尝试 passive = false
  • 二进制模式：传输图片、视频等二进制文件务必保持二进制模式（默认开启）
  • 权限不足：确认 FTP 账号对目标目录有读写权限

3. 中文文件名乱码 ​

不同 FTP 服务器默认编码不同，若遇乱码，可通过服务器设置统一使用 UTF-8 编码。

4. 上传大文件超时 ​

大文件传输耗时较长，可适当调大 timeout 参数（毫秒）。

注意事项 ​

  • 连接复用：同一连接可重复执行多个操作，用完务必调用 disconnect() 释放
  • 线程安全：FTP 连接为会话级对象，多线程并发操作需各自建立连接
  • 目录删除：deleteDir() 只能删除空目录，需先清空其中文件
  • 路径格式：远程路径使用 / 分隔，如 /uploads/images/photo.jpg
  • FTPS 支持：内置支持隐式（端口 990）与显式 TLS 两种 FTPS 模式
