OpencvOps_图像处理 ​

模块简介 ​

OpencvOps 封装了 官方 OpenCV 4.5.3 Java API，对外提供常用图像预处理能力。

设计约定（Mat 句柄模式） ​

本类采用 Mat 句柄模式，与传统的 JSON 返回接口不同：

  • 入参统一为 Mat 句柄：接口不再接收 bitmap，统一接收 Mat 池句柄（如 mat_1）。
  • 返回统一为 Mat 句柄：各接口处理结果写入 Mat 池并返回新句柄，可直接传给下一个接口。
  • 统一转换入口：bitmap 通过 bitmapToMat(bitmap) 转成 Mat 句柄后再进入处理链路。
  • 返回类型均为 String 句柄：不再返回 JSON，句柄即结果，失败返回空字符串 ""。

功能概览 ​

  • 统一转换：bitmapToMat(bitmap) —— Bitmap 转 Mat 句柄（入口）
  • 灰度处理：matToGray(matId) —— 彩色图转单通道灰度图
  • 二值化处理：matThreshold(matId, thresh, maxval, type) —— 固定阈值二值化
  • 双阈值二值化：matDoubleThreshold(matId, lowThresh, highThresh, maxval) —— 区间保留二值化
  • 自适应二值化：matAdaptiveThreshold(matId, maxValue, adaptiveMethod, thresholdType, blockSize, c) —— 局部自适应二值化
  • 保存：saveMat(matId, path) —— Mat 句柄保存为图片文件（自动创建父目录）
  • 回收：recycle(matId) / clearMats() —— 释放 Mat 池内存
  • 回收校验：isRecycled(matId) —— 判断 Mat 句柄是否已回收

架构与设计原则 ​

懒人精灵(Lua)

   │  opencvOps.matToGray(mat_1)           -- 句柄入参 -> 句柄返回
   │  opencvOps.matThreshold(mat_2, ...)
   ▼
Kotlin OpencvOps.kt（Mat 句柄模式，Lua 友好）
   │  org.opencv 官方 Java API
   ▼
OpenCV 4.5.3（libopencv_java4.so，4 个 ABI）

核心特性：

  • Mat 句柄复用：所有 Mat 缓存在 Mat 池，用句柄访问，避免反复 JNI 传输大图
  • 链式处理：上一接口返回的句柄可直接传给下一接口，无需中间转换
  • 统一转换：bitmapToMat 是 Bitmap 进入处理链路的唯一入口
  • 全 ABI：arm64-v8a / armeabi-v7a / x86 / x86_64 均已编译
  • Lua 友好：参数与返回均为基础类型（String / Int / Double / Bitmap）

通用约定 ​

返回约定 ​

  • 各处理接口返回 新 Mat 句柄字符串（如 mat_1），可直接传给下一个接口。
  • 处理失败返回空字符串 ""。
  • bitmapToMat 返回 Mat 句柄，失败返回 ""。
  • saveMat 返回 Boolean（保存是否成功）。
  • recycle 返回 Boolean（是否成功回收，句柄不存在返回 false）。
  • isRecycled 返回 Boolean（是否已回收）。
  • matInfo 返回 JSON 字符串（供调试查看 Mat 尺寸/通道）。

错误处理 ​

由于接口直接返回句柄，脚本侧需判断返回值：

  • 返回 "" 或 nil 表示处理失败（native 库未加载、句柄不存在、参数非法等）。
  • 传入不存在的 Mat 句柄会返回 ""。
  • matDoubleThreshold 要求 lowThresh <= highThresh，否则返回 ""。
  • matAdaptiveThreshold 要求 blockSize 为正奇数，否则返回 ""。

Mat 句柄生命周期 ​

  • 所有 Mat 缓存在 Mat 池中，用句柄访问。
  • 务必在不再使用后调用 recycle(matId) 释放。
  • recycle 返回 Boolean，可用于判断句柄是否真的回收成功。
  • 回收后可用 isRecycled(matId) 校验句柄是否已不在 Mat 池中。
  • 批量处理可调用 clearMats() 一次性清空。
  • 需要保存结果用 saveMat(matId, path)。
  • 需要转回 Bitmap 用 matToBitmap(matId)。

二值化处理 ​

matThreshold(matId, thresh, maxval, type) ​

将灰度图按固定阈值分成黑白两值（0 或 maxval）。

参数名类型必填说明
matIdString是输入 Mat 句柄
threshDouble是阈值（0~255）
maxvalDouble是最大值（一般为 255）
typeInt是二值化类型，见下表

type 取值：

type名称说明
0BINARYsrc > thresh 取 maxval，否则取 0
1BINARY_INVsrc > thresh 取 0，否则取 maxval
2TRUNCsrc > thresh 取 thresh，否则取原值
3TOZEROsrc > thresh 取原值，否则取 0
4TOZERO_INVsrc > thresh 取 0，否则取原值
8OTSU大津法自动计算阈值（thresh 作为初始值）
16TRIANGLE三角法自动计算阈值
返回值类型说明
String新 Mat 句柄，失败返回 ""

示例：

lua
local opcvOps = UtilsMain.opencvOps()
local bmp = LuaEngine.snapShot(0, 0, 0, 0)
local srcMat = opcvOps.bitmapToMat(bmp)
local grayMat = opcvOps.matToGray(srcMat)
local resultMat = opcvOps.matThreshold(grayMat, 127, 255, 0)  -- BINARY 二值化
opcvOps.saveMat(resultMat, "/storage/emulated/0/Pictures/threshold.png")

opcvOps.recycle(srcMat)
opcvOps.recycle(grayMat)
opcvOps.recycle(resultMat)

双阈值二值化 ​

matDoubleThreshold(matId, lowThresh, highThresh, maxval) ​

通过两次阈值实现 区间保留：低于 lowThresh 或高于 highThresh 的像素置 0，区间内的像素置 maxval。适合提取固定亮度区间的前景（如高亮目标、固定色阶区域）。

实现方式：先做 BINARY（> lowThresh 保留），再做 BINARY_INV（< highThresh 保留），最后 bitwise_and 取交集。

参数名类型必填说明
matIdString是输入 Mat 句柄
lowThreshDouble是低阈值（0~255）
highThreshDouble是高阈值（0~255，需 >= lowThresh）
maxvalDouble是区间内像素值（一般为 255）
返回值类型说明
String新 Mat 句柄，失败返回 ""

示例：

lua
local opcvOps = UtilsMain.opencvOps()
local bmp = LuaEngine.snapShot(0, 0, 0, 0)
local srcMat = opcvOps.bitmapToMat(bmp)
local grayMat = opcvOps.matToGray(srcMat)
-- 保留 100~200 亮度区间的像素
local resultMat = opcvOps.matDoubleThreshold(grayMat, 100, 200, 255)
opcvOps.saveMat(resultMat, "/storage/emulated/0/Pictures/double_threshold.png")

opcvOps.recycle(srcMat)
opcvOps.recycle(grayMat)
opcvOps.recycle(resultMat)

自适应二值化 ​

matAdaptiveThreshold(matId, maxValue, adaptiveMethod, thresholdType, blockSize, c) ​

根据每个像素邻域的局部特性自动计算阈值，对光照不均、背景渐变的图像效果更好。

参数名类型必填说明
matIdString是输入 Mat 句柄
maxValueDouble是最大值（一般为 255）
adaptiveMethodInt是自适应方法：0 = 邻域均值(MEAN_C)，1 = 邻域高斯加权(GAUSSIAN_C)
thresholdTypeInt是二值化类型：0 = BINARY，1 = BINARY_INV
blockSizeInt是邻域块大小（必须为正奇数，如 3、5、7）
cDouble是从均值/加权均值减去的常数，通常 2~15
返回值类型说明
String新 Mat 句柄，失败返回 ""

示例：

lua
local opcvOps = UtilsMain.opencvOps()
local bmp = LuaEngine.snapShot(0, 0, 0, 0)
local srcMat = opcvOps.bitmapToMat(bmp)
local grayMat = opcvOps.matToGray(srcMat)
-- 高斯加权自适应二值化，块大小 15，常数 10
local resultMat = opcvOps.matAdaptiveThreshold(grayMat, 255, 1, 0, 15, 10)
opcvOps.saveMat(resultMat, "/storage/emulated/0/Pictures/adaptive.png")

opcvOps.recycle(srcMat)
opcvOps.recycle(grayMat)
opcvOps.recycle(resultMat)

保存 / 回收 ​

saveMat(matId, path) ​

将 Mat 句柄保存为图片文件（按扩展名自动选择 PNG / JPG）。

保存前会自动判断并创建父目录（多级目录逐级创建），因此目录不存在也能正常保存，不会因目录缺失返回 false。

参数名类型必填说明
matIdString是Mat 句柄
pathString是保存路径，如 /storage/emulated/0/Pictures/result.png
返回值类型说明
Boolean保存成功返回 true，失败返回 false

recycle(matId) ​

回收单个 Mat 句柄。

参数名类型必填说明
matIdString是一个 Mat 句柄
返回值类型说明
Boolean回收成功（句柄原本存在并已从 Mat 池移除）返回 true；句柄不存在或参数为空返回 false

示例：

lua
opcvOps.recycle(srcMat)
opcvOps.recycle(grayMat)
opcvOps.recycle(resultMat)

-- 回收后校验是否成功
print("srcMat 已回收:", opcvOps.recycle(srcMat))
print("srcMat 是否已回收:", opcvOps.isRecycled(srcMat))

性能优化策略 ​

1. 链式复用 Mat 句柄 ​

处理链路全程用 Mat 句柄传递，避免每次重新转 Bitmap：

lua
local srcMat = opcvOps.bitmapToMat(bmp)
local grayMat = opcvOps.matToGray(srcMat)
local resultMat = opcvOps.matThreshold(grayMat, 127, 255, 0)
-- 继续使用 resultMat ...
opcvOps.recycle(srcMat)
opcvOps.recycle(grayMat)
opcvOps.recycle(resultMat)

2. 及时释放 ​

  • 每个 Mat 句柄用完即 recycle
  • 脚本结束时调用 clearMats() 释放全部
  • 循环处理时每轮产生的 Mat 及时回收

3. 算法选择 ​

场景推荐
光照均匀的固定阈值分割matThreshold（BINARY）
光照不均、背景渐变matAdaptiveThreshold
提取固定亮度区间matDoubleThreshold
前景亮度不确定matThreshold（OTSU，type=8）

错误处理机制 ​

由于接口直接返回 Mat 句柄，脚本侧通过判空处理异常：

lua
local resultMat = opcvOps.matToGray(srcMat)
if resultMat ~= nil and resultMat ~= "" then
    -- 成功，resultMat 为灰度句柄
else
    -- 失败，可能是句柄不存在、native 库未加载、参数非法
end

防御性编程建议：

  1. 每次调用后判断返回句柄是否为 "" 或 nil
  2. matAdaptiveThreshold 的 blockSize 必须为正奇数，否则返回 ""
  3. matDoubleThreshold 的 lowThresh 必须 <= highThresh
  4. Mat 句柄使用完毕后务必 recycle 释放

跨平台兼容性 ​

  • 全 ABI 支持：arm64-v8a / armeabi-v7a / x86 / x86_64
  • 官方 Java API：基于 OpenCV 4.5.3 自编库，使用完整 org.opencv 官方 API
  • 系统要求：Android 7.0+（minSdk 24）
  • native 库：libopencv_java4.so，通过 System.loadLibrary("opencv_java4") 加载
