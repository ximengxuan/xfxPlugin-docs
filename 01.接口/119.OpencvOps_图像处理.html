OpencvOps_图像处理 ​

模块简介 ​

OpencvOps 提供常用图像预处理能力。

  • 系统要求：Android 7.0+（minSdk 24）

功能概览 ​

  • 统一转换：bitmapToMat(bitmap) —— Bitmap 转 Mat 句柄（入口）
  • 灰度处理：matToGray(matId) —— 彩色图转单通道灰度图
  • 二值化处理：matThreshold(matId, thresh, maxval, type) —— 固定阈值二值化
  • 双阈值二值化：matDoubleThreshold(matId, lowThresh, highThresh, maxval) —— 区间保留二值化
  • 自适应二值化：matAdaptiveThreshold(matId, maxValue, adaptiveMethod, thresholdType, blockSize, c) —— 局部自适应二值化
  • 颜色空间转换：getHSV(matId, type) / getHLS(matId, type) / getBGR(matId, type) —— 全图或单通道
  • 边缘检测：findCannys(matId, threshold1, threshold2, apertureSize, L2gradient) —— Canny 边缘检测
  • 形状检测：findLines / findCircles / findPolygons —— 直线 / 圆 / 凸包形状检测
  • 凸包：getConvexHull / isContourConvex
  • 轮廓处理：getContours / getContoursRect / getContoursCircles / getContoursLength / getContoursArea / getContoursHierarchy / getContoursMoments
  • 形态学操作：dilate / erode / open / close / topHat / blackHat / gradient / skeleton
  • 滤波：absDiff / medianBlur / gaussianBlur / blur / bilateral / filter2D
  • 颜色范围 / 掩膜：inRange / copyTo
  • 几何变换：warpPerspective（透视变换）
  • 投影：projection / projectionValue（行 / 列投影）
  • 保存：saveMat(matId, path) —— Mat 句柄保存为图片文件（自动创建父目录）
  • 回收：recycle(matId) / clearMats() —— 释放 Mat 池内存
  • 回收校验：isRecycled(matId) —— 判断 Mat 句柄是否已回收

API 接口列表 ​

统一转换 ​

bitmapToMat(bitmap) ​

将 Bitmap 存入 Mat 池，返回 Mat 句柄。这是 Bitmap 进入处理链路的统一入口。

参数名类型必填说明
bitmapBitmap是输入 Bitmap（如懒人精灵截图）
返回值类型说明
StringMat 句柄（如 mat_1），失败返回 ""

matToBitmap(matId) ​

将 Mat 句柄转回 Bitmap。

参数名类型必填说明
matIdString是Mat 句柄
返回值类型说明
BitmapBitmap 对象，失败返回 null

灰度处理 ​

matToGray(matId) ​

将彩色图转换为单通道灰度图（BGR -> GRAY），是二值化、边缘检测等预处理的第一步。

参数名类型必填说明
matIdString是输入 Mat 句柄
返回值类型说明
String新 Mat 句柄（单通道灰度图），失败返回 ""

二值化处理 ​

matThreshold(matId, thresh, maxval, type) ​

将灰度图按固定阈值分成黑白两值（0 或 maxval）。

参数名类型必填说明
matIdString是输入 Mat 句柄
threshDouble是阈值（0~255）
maxvalDouble是最大值（一般为 255）
typeInt是二值化类型，见下表

type 取值：

type名称说明
0二值化 BINARYsrc > thresh 取 maxval，否则取 0
1反向二值化 BINARY_INVsrc > thresh 取 0，否则取 maxval
2截断 TRUNCsrc > thresh 取 thresh，否则取原值
3取零 TOZEROsrc > thresh 取原值，否则取 0
4反取零 TOZERO_INVsrc > thresh 取 0，否则取原值
8OTSU大津法自动计算阈值（thresh 作为初始值）
16TRIANGLE三角法自动计算阈值
返回值类型说明
String新 Mat 句柄，失败返回 ""

双阈值二值化 ​

matDoubleThreshold(matId, lowThresh, highThresh, maxval) ​

通过两次阈值实现 区间保留：低于 lowThresh 或高于 highThresh 的像素置 0，区间内的像素置 maxval。

参数名类型必填说明
matIdString是输入 Mat 句柄
lowThreshDouble是低阈值（0~255）
highThreshDouble是高阈值（0~255，需 >= lowThresh）
maxvalDouble是区间内像素值（一般为 255）
返回值类型说明
String新 Mat 句柄，失败返回 ""

自适应二值化 ​

matAdaptiveThreshold(matId, maxValue, adaptiveMethod, thresholdType, blockSize, c) ​

根据每个像素邻域的局部特性自动计算阈值，对光照不均、背景渐变的图像效果更好。

参数名类型必填说明
matIdString是输入 Mat 句柄
maxValueDouble是最大值（一般为 255）
adaptiveMethodInt是自适应方法：0 = 邻域均值(MEAN_C)，1 = 邻域高斯加权(GAUSSIAN_C)
thresholdTypeInt是二值化类型：0 = BINARY，1 = BINARY_INV
blockSizeInt是邻域块大小（必须为正奇数，如 3、5、7）
cDouble是从均值/加权均值减去的常数，通常 2~15
返回值类型说明
String新 Mat 句柄，失败返回 ""

local sMat   = opcvOps.getHSV(srcMat, 1)   -- S 通道（饱和度）
local vMat   = opcvOps.getHSV(srcMat, 2)   -- V 通道（明暗）

边缘/轮廓检测 ​

findCannys(matId, threshold1, threshold2, apertureSize, L2gradient) ​

Canny 边缘检测，输入通常为灰度图，输出二值边缘图。

参数名类型必填说明
matIdString是输入 Mat 句柄（灰度图）
threshold1Double是弱阈值（默认 50）
threshold2Double是强阈值（默认 100）
apertureSizeInt是Sobel 算子大小（默认 3，可为 3、5、7）
L2gradientBoolean是是否使用更精确的 L2 范数（默认 false）
返回值类型说明
String新 Mat 句柄（单通道边缘图），失败返回 ""

形状检测 ​

findLines(matId, src_multiple, rho, theta, threshold, minLineLength, maxLineGap, weakThreshold, strongThreshold) ​

直线检测（内部先做 Canny 边缘检测，再做 HoughLinesP）。

参数名类型必填说明
matIdString是输入 Mat 句柄（灰度图）
src_multipleDouble是缩放比例（默认 1.0）
rhoInt是步长（像素，默认 1）
thetaInt是角度（度，默认 1；如 90 只检测水平和竖直的线）
thresholdInt是连续检测到多少个 rho 点认为是一条直线（默认 10）
minLineLengthInt是最小线段长度（默认 50）
maxLineGapInt是两直线间缺多少像素仍认为是同一条直线（默认 5）
weakThresholdInt是Canny 弱阈值（默认 50）
strongThresholdInt是Canny 强阈值（默认 100）
返回值类型说明
StringJSON 数组，如 [[x1,y1,x2,y2],...]，失败返回 ""

示例：

lua
-- 每隔 1 度检测一次
local lines = opcvOps.findLines(srcMat, 1.0, 1, 1, 10, 50, 10, 50, 100)
print(lines)  -- [[x1,y1,x2,y2],...]

轮廓处理 ​

以下轮廓接口的 mode 与 method 语义一致：

  • mode：0 只检测最外围轮廓（内围忽略）；1 检测所有轮廓但不建等级；2 检测所有轮廓并建立两级等级（外围为顶层）
  • method：1 保存边界所有连续点；2 仅保存拐点（拐点间直线段信息点不保留）

contoursIndex 用于筛选轮廓。只要 mode 和 method 一样，各轮廓函数返回的数组是一一对应的，如 轮廓重心[5] 与 轮廓长度[5] 是同一个轮廓的信息。

getContours(matId, mode, method, contoursIndex, thickness, lineType) ​

二值化图轮廓提取/绘制。把选中的轮廓绘制到黑色画布上，返回画好的图片。

参数名类型必填说明
matIdString是输入 Mat 句柄（二值图）
modeInt否轮廓检索模式（0、1、2，默认 0）
methodInt否轮廓近似方法（1、2，默认 2）
contoursIndexString否要绘制的轮廓索引数组，默认空字符串表示全部
thicknessInt否线条宽度，-1 表示填充（默认 1）
lineTypeInt否线条类型：8 不抗锯齿，16 抗锯齿（默认 8）
返回值类型说明
String新 Mat 句柄（轮廓图片），失败返回 ""

示例：

local allContours = opcvOps.getContours(binaryMat, 0, 2, "", 1, 8)     -- 全部轮廓
local twoContours = opcvOps.getContours(binaryMat, 2, 2, "[1,7]", 1, 8) -- 第 1、7 个轮廓
local filled      = opcvOps.getContours(binaryMat, 2, 2, "[1,7]", -1, 8) -- 填充第 1、7 个

形态学操作 ​

以下操作输入为二值化图片，返回新 Mat 句柄，失败返回 ""。共同参数：

参数名类型必填说明
matIdString是输入 Mat 句柄（二值化图）
structTypeInt否结构元素类型：0 矩形，1 十字架型，2 椭圆形（默认 0）
structWidthInt否结构元素宽度（默认 5）
structHeightInt否结构元素高度（默认 5）
anchorXInt否结构元素锚点 x（默认 -1 表示中心）
anchorYInt否结构元素锚点 y（默认 -1 表示中心）
iterationsInt否迭代次数（默认 1）

dilate(matId, structType, structWidth, structHeight, anchorX, anchorY, iterations) ​

膨胀：使前景区域扩大，填充小孔。

erode(matId, structType, structWidth, structHeight, anchorX, anchorY, iterations) ​

腐蚀：使前景区域缩小，去除小噪点。

open(matId, structType, structWidth, structHeight, anchorX, anchorY, iterations) ​

开操作（腐蚀+膨胀）：去除小噪点、断开细小连接。

close(matId, structType, structWidth, structHeight, anchorX, anchorY, iterations) ​

闭操作（膨胀+腐蚀）：填充小孔、连接断裂区域。

topHat(matId, structType, structWidth, structHeight, anchorX, anchorY, iterations) ​

顶帽（原图 - 开操作）：提取比邻域亮的部分。

blackHat(matId, structType, structWidth, structHeight, anchorX, anchorY, iterations) ​

黑帽（闭操作 - 原图）：提取比邻域暗的部分。

gradient(matId, structType, structWidth, structHeight, anchorX, anchorY, iterations) ​
